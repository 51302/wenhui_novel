# 净无痕写作风格

- 情绪结构：把轻视、规则压迫和无力感写具体，形成可追溯的积压。
- 结尾钩子：在结尾释放主角即将反击或改变局面的信号。
- 节奏：前段积累，后段收紧，不提前消耗爆发效果。
- 避免：不能用无依据的愤怒替代人物受辱的具体过程。
