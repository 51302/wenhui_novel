# 圣骑士的传说写作风格

- 对话：把传音、留言和围观写出群聊、八卦或社交互动的节奏。
- 幽默：使用吐槽、误会和人物反差制造笑点，但不破坏世界观规则。
- 节奏：笑点服务于人物关系和剧情推进，不让段子取代事件。
- 世界观：现代社交表达只能改变沟通质感，不能抹平仙侠设定的代价。
