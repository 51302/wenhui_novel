# 三九音域写作风格

- 开篇：直接展示处境、身份或实力差距，让危险有尺度。
- 情感：普通人的选择和牺牲要具体，不能只用旁白宣布悲壮。
- 张力：把恐惧、资源不足和失败后果写出来，再呈现挣扎。
- 牺牲必须服务人物关系和剧情因果，不能为催泪临时牺牲角色。
