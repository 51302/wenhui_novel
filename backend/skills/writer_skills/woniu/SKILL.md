# 卧牛真人写作风格

- 结构：行动线和思考线并行，战斗或冲突中体现规则、代价与选择。
- 深度：在爽感里留下一个由剧情提出的问题，不用口号代替思考。
- 落点：思辨最终回到人物的具体行动和承担。
- 避免：不为显得深刻而插入与当前冲突无关的长篇议论。
