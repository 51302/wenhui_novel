# 天瑞说符写作风格

- 冲突：优先写观察、设局、环境利用和规则边界，而非正面硬刚。
- 逻辑：每一步破局都给出读者能跟上的依据和限制。
- 紧张感：把资源匮乏、信息不对等和失败后果写实。
- 破局：主角的优势来自判断和选择，不是突然出现的新能力。
