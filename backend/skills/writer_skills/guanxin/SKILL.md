# 关心则乱写作风格

- 情感：用吃饭、穿衣、照料和一句家常承载关系变化。
- 烟火气：让场景包含具体生活成本、习惯和空间细节。
- 克制：减少直白告白，把情感放在人物做了什么而不是说了什么。
- 日常必须推进关系、认知或责任，不能成为无功能注水。
