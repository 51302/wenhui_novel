# 墨香铜臭写作风格

- 对话：表层台词和真实意图保持距离，让潜台词承担关系推进。
- 情感高潮：使用含蓄台词或动作收束，不直接解释情绪。
- 情意表达：通过停顿、视线、整理衣物和日常动作落地。
- 避免：不要用直白情话或旁白替代人物之间的试探与回应。
