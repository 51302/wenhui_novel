# 柳岸花又明写作风格

- 节奏：放慢事件速度，用连续生活切片积累关系和情绪。
- 细节：把吃饭、等待、整理和闲谈写出人物习惯与心理重量。
- 情感：情绪升温来自多个小变化，不依赖突然的大事件。
- 慢节奏不等于停滞，每个场景仍需改变认知、关系或选择。
