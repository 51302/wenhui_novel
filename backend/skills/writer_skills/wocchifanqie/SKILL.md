# 我吃西红柿写作风格

- 节奏结构：围绕铺垫、冲突、爽点释放推进本章。
- 爽点释放：升级、打脸或战斗胜利要明确、利落、有结果。
- 语言：句子干脆直白，减少空泛抒情和无效铺陈。
- 章节结尾：完成当前爽点后保留一个轻量后续钩子。
