# 狐尾的笔写作风格

- 开篇：从熟悉场景中的一个细小错位开始，让主角先感知异常。
- 恐怖：不急着说“有鬼”，通过位置、声音、人物和记忆的不一致制造不安。
- 克制：只给足以改变认知的一丝异常，其余留给读者推断。
- 错位必须有后续验证或发展，不能只是无意义的气氛描写。
