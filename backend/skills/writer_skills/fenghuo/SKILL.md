# 烽火戏诸侯写作风格

- 对话：配角也要有独立声音和可记忆的表达。
- 情感：用差一点、错过和未完成制造余韵，不强行圆满。
- 关键节点：重大选择或战斗后可用一句克制的哲理式旁白收束。
- 金句必须服务人物处境和剧情，禁止脱离场景硬塞格言。
