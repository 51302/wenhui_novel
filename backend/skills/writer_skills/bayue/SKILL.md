# 八月长安写作风格

- 心理：让内心活动参与事件推进，但必须落到具体记忆、选择和感受。
- 情感：用眼神、停顿、别过脸等微小细节表达情绪变化。
- 节奏：允许情节密度较低，但每一层情绪都要有新变化。
- 避免：不直接宣布人物“很爱”“很难过”，改用可观察行为呈现。
