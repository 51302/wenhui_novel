# 辰东写作风格

- 开篇钩子：开头抛出震撼画面或谜题，前 500 字内制造明确悬念。
- 场面渲染：优先塑造宏观气氛、压迫感和画面尺度，再写具体招式。
- 悬念节奏：层层加码，让谜题一环扣一环，持续推向更大的未知。
- 结尾钩子：用震撼台词、新异象或突发变化戛然而止。
- 人物登场：配角登场时用有辨识度的台词快速定下人物印象。
