# 外挂与系统设定设计

## 定位

金手指是「机制层」能力，与主题材（玄幻、都市、末世、历史等）组合使用，不单独成篇。适用范围：任务系统、属性面板、签到、抽奖、模拟器、随身空间、传承、重生记忆与特殊天赋。

核心一句：外挂提供机会而非替代决策，主角仍需学习、选择与承担代价。系统再强，落地成剧情的永远是主角在有限信息下做的取舍。

一句话检查（写完本章自问）：本章的系统/外挂是否制造了新的选择与代价，而不是直接给出答案？如果系统一响就把难题解决了，主角没有付出也没有选择，这段外挂就是空转，重写成「给机会 → 主角权衡 → 付出代价才兑现」。

## 设计前必答（缺一项先问，不要用"到时候再编"填空）

- 来源是否已知：外挂从哪来，是否需要在正文交代或刻意留悬念。
- 触发条件：什么动作/状态/时机能激活，旁人能否察觉。
- 效果范围：能做什么、明确不能做什么。
- 成本：每次使用消耗什么（体力、寿命、情报暴露、代价物）。
- 频率与上限：多久能用一次、单位内封顶多少、是否有冷却。
- 成长条件：靠什么升级，升级带来的新权限与新限制各是什么。
- 系统是否有人格：若有，需给出稳定的动机与权限边界，不随剧情需要临时变性格。

## 落地规则（量化）

- 奖励对应世界内价值与稀缺性：给出的资源/能力，其强度要与该世界的稀缺度匹配，不凭空造超规格奖励。
- 随机机制先定规则再摇：抽奖/爆率的规则本章内先明示或已确立，不在结果不利时暗改概率。
- 模拟器明确信息可信度：推演结果是「参考」还是「必然」要说清，允许有偏差与盲区。
- 空间明确时间与进出限制：随身空间的时间流速、容量、进出条件、能带什么不能带什么，一次立规、后文遵守。
- 重生记忆受限：受时间跨度、原有认知水平与蝴蝶效应制约，越往后原记忆越失效，不做全知全能。
- 界面只展示影响当前选择的信息：系统面板/弹窗只呈现主角当下决策需要的数据，不铺无用数值。
- 弹窗与结算克制：单章系统弹窗/结算次数 ≤ 该章场景真正需要的次数，删除无剧情作用的奖励结算段。

## 与主题材协作

- 任务须与人物价值/时间/资源产生张力：系统任务不能只是「做了就有奖」，要逼主角在想要的东西之间取舍。
- 失败与拒绝有事先可理解的后果：惩罚规则在触发前已让读者可知，不搞事后才冒出来的惩罚。
- 关键转折由可追溯的行为、线索或条件促成，偶然可引出问题但不反复代替主角解决问题。
- 不临时开新功能救场：主角陷入困境时，不给系统凭空添加一个正好能解围的新能力。
- 不暗改概率或惩罚：既定的爆率、冷却、代价一经确立，后文一致执行。

- [ ] 主角没有靠临时新增的系统功能脱困 → 勾不上回「与主题材协作」，改成用已有规则或主角行动解决。

## 量化反套路红线（写完核对，超标即改）

- 临时新增系统功能救场：0 次。
- 暗改概率/惩罚（含事后才冒出的规则）：0 次。
- 主角靠系统直接给答案、自己不做任何选择：0 处。
- 无剧情作用的纯奖励结算段：0 段。
