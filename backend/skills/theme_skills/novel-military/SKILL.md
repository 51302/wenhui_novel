# 军事题材小说 Skill

## 读者承诺

军事读者追的是「在纪律、协同和战场规则的约束下，靠判断与代价换来推进」。番号、装备、战术术语都是这条循环的外壳，不是内容本身。

一句话检查（写完本章自问）：删掉所有番号、装备名词、军种术语之后，这一章是否还剩「某个决策 → 战局或关系发生可量化变化」？如果只剩气氛和名词堆砌，这章还没进入军事，回到「决策—代价—战局变化」重写。

## 开书先定（缺一项先问，不要用"到时候再编"填空）

- 战场/军旅背景与规则：真实历史还是架空战事，交战规则、编制层级、信息不确定性一句话说清。
- 主角军职与职责：军衔、岗位、指挥或被指挥的关系，他对什么负责。
- 敌我态势与升级曲线：双方兵力、目标、优劣势，接下来态势如何一步步加压。
- 纪律与协同约束：命令链、交战规则、后勤补给、通信条件对行动的硬限制。
- 前三章军事承诺：读者前三章能看到的最大军事看点（一次决断、一场交锋或一个战局反转）。
- 中期两道战役门槛：接下来两场必须打赢或撑过的关键战事。

## 前三章承诺链

- 第 1 章：抛出一个可执行的任务压力（不是背景介绍），主角必须当场做出军事决断。
- 第 2 章：主角的能力/纪律可验证——换一个在场战友也能描述"他做了什么、对不对"。
- 第 3 章：一次行动改变战局或处境，前两章的决断产生可追溯的战场后果。

读完三章，读者要能回答：主角要完成什么任务、他凭什么能打、接下来要过哪场硬仗。

## 本章场景写法（按需选 1-2 种，每种给出量化计数）

- 战斗/战术推演：战术依据≥1（地形/情报/协同/规则利用），代价/伤亡≥1（消耗/受伤/减员/暴露），战局变化≥1（态势推进或恶化）。必须体现态势、地形、协同、消耗，不能只报武器名。失败模式：敌方为让主角赢突然集体犯蠢 → 给敌方一个合理的失误来源或情报盲区。
- 协同/指挥抉择：战术依据≥1（权衡兵力/时间/风险），代价/伤亡≥1（有人为决策买单），战局变化≥1（指挥结果落地）。失败模式：命令零成本下达、下级无条件执行 → 加入分歧、执行摩擦或误解。
- 军旅关系与磨合：战术依据≥1（关系服务于任务而非闲聊），代价/伤亡≥1（信任/立场/位置的代价），战局变化≥1（关系变化影响协同）。失败模式：配角只负责烘托主角 → 给他与主角冲突的诉求或职责。
- 情报/侦察：战术依据≥1（获取或误判情报），代价/伤亡≥1（暴露/牺牲/时间窗口），战局变化≥1（情报改变下一步部署）。失败模式：情报凭空到手无风险 → 加竞争者、反侦察或可信度存疑。

## 成文软区间（是软参考，不是合格线）

句长 20–30 字为主、长短交替；对白约占两成；战术细节密度适中，够支撑判断即可。术语解释打断动作，比字数偏离更严重。数字不达标不算错，判断被术语淹没才算错。

## 交付自检（每条勾不上就回到对应写法改）

- [ ] 本章有明确军事结果（打赢/撑住/撤退/夺点/情报兑现/关系变化）→ 勾不上回「战斗/战术推演」。
- [ ] 主角的胜利或推进有可追溯的战术依据 → 勾不上回对应场景写法。
- [ ] 本章至少有一次"决策被战场检验"的具体行动，而非术语描述 → 勾不上：删名词、加行动、加约束。
- [ ] 章末留了新任务/新威胁/新情报/更高战役目标之一的钩子 → 勾不上补钩子。

## 量化反套路红线（写完核对，超标即改）

- 胜利无代价、无伤亡：≤1 次（再多必须插入消耗或减员）。
- 敌方为让主角赢集体失误：0 次（失误必须有可信来源）。
- 主角违反基本军事常识却被夸神机妙算：0 次。
- 番号/装备罗列但无战术作用：0 处。
