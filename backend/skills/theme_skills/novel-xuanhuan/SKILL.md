# 玄幻修仙小说 Skill

## 读者承诺

玄幻读者追的是「主角做一件事 → 力量规则给出反馈 → 处境向上变化」的正反馈循环。境界、功法、势力都是这条循环的外壳，不是内容本身。

一句话检查（写完本章自问）：删掉所有境界名、功法名、势力名之后，这一章是否还剩「他做了一件事 → 规则给了反馈 → 下一步变了」？如果只剩气氛和名词堆砌，这章还没进入玄幻，回到「获得—代价—下一阈值」重写。

## 开书先定（缺一项先问，不要用"到时候再编"填空）

- 核心超常卖点：主角凭什么与众不同，一句话说清。
- 初始处境与欲望：他现在被什么卡住，最想要什么。
- 力量如何触发/被看见：能力怎么发动，旁人怎么察觉。
- 边界与代价：能力的上限、消耗、失败条件是什么。
- 前三章超常承诺：读者前三章能看到的最大爽点。
- 中期两道门槛：接下来两个必须跨过的障碍。

## 前三章承诺链

- 第 1 章：抛出一个可执行的压力（不是背景介绍），主角必须当场做选择。
- 第 2 章：超常能力可验证——换一个在场的人也能描述"发生了什么"。
- 第 3 章：反馈改变下一步，主角处境或目标因前两章而变化。

读完三章，读者要能回答：主角想要什么、他有什么别人没有的、接下来要跨什么坎。

## 本章场景写法（按需选 1-2 种，每种给出量化计数）

- 获得—代价—下一阈值：获得≥1（新力量/资源/情报），代价≥1（消耗/受伤/暴露/失去），下一阈值≥1（更高目标或新限制）。失败模式：突破后全员原地欢呼庆祝、升级无任何代价 → 改成付出后才拿到。
- 战斗：必须体现境界差异、环境影响、招式选择和消耗，不能只报技能名。主角获胜要有依据（准备/情报/规则利用/牺牲/临场判断）。失败模式：敌人为让主角赢突然变蠢 → 给敌人一个合理的失误来源。
- 夺宝/秘境：机会必须有竞争者和风险成本，宝物带缺陷或后患。失败模式：捡到就变强无副作用 → 加代价或觊觎者。
- 结盟/势力博弈：配角有独立目标，不只负责嘲讽或送经验。失败模式：配角只为衬托主角而存在 → 给他一个和主角冲突的诉求。

## 成文软区间（是软参考，不是合格线）

句长 20–30 字为主、长短交替；对白约占两成；解释性文字打断动作，比字数偏离更严重。数字不达标不算错，动作被解释淹没才算错。

## 交付自检（每条勾不上就回到对应写法改）

- [ ] 本章有明确目标达成（突破/夺宝/结盟/破局/复仇/揭设定）→ 勾不上回「获得—代价—下一阈值」。
- [ ] 主角的成长或胜利有可追溯依据 → 勾不上回「战斗」。
- [ ] 本章至少有一次"力量被看见"的具体动作，而非名词描述 → 勾不上：删名词、加动手、加限制。
- [ ] 章末留了新敌人/新限制/新线索/更高目标之一的钩子 → 勾不上补钩子。

## 量化反套路红线（写完核对，超标即改）

- 连续无代价升级/获宝：≤1 次（再多必须插入代价）。
- 纯设定介绍段（不含动作与选择）：全章 ≤1 段。
- "气势一震 / 全场震惊 / 不敢置信"式空镜替代战斗过程：0 次。
- 境界名/功法名罗列但能力无差异体现：0 处。
