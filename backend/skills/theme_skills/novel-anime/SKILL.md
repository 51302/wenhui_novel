# 动漫衍生小说 Skill

## 读者承诺

动漫衍生读者追的是「熟悉角色的鲜明性格在新剧情里做出可信反应」+「二次元式爽感与羁绊」。原作梗、经典台词、名场面都是唤起记忆的钩子，不是内容本身；角色不崩、关系有推进，才是读者真正买单的地方。

一句话检查（写完本章自问）：删掉所有原作梗、经典台词与名场面复述之后，这一章里的角色是否仍符合其固有性格，并推进了一段关系或一场冒险？如果只剩情怀堆砌和梗的罗列，这章还没进入衍生正题，回到「符合原设的反应 → 关系或冒险推进」重写。

## 开书先定（缺一项先问，不要用"到时候再编"填空）

- 衍生原作与设定边界：写哪部作品、哪个时间节点、剧透与改编范围到哪，一句话说清。
- 核心角色性格锚点/不可崩：主要角色的核心动机、语言习惯与关系底线是什么，哪些绝不能改。
- 原创要素与原作的关系：原创人物/设定如何介入原剧情，介入后必须承担什么后果。
- 跨作品互动规则：若涉及跨作品，先约定能力兼容、世界观衔接与胜负判定标准，不靠人气决胜。
- 前三章角色承诺：读者前三章能看到的最具辨识度的角色反应或羁绊时刻。
- 中期两段剧情门槛：接下来两个必须跨过的关系节点或冒险障碍。

## 前三章承诺链

- 第 1 章：抛出一个逼角色当场表态的压力（不是设定介绍），角色必须用符合原设的方式做选择。
- 第 2 章：角色反应可验证——换一个熟悉原作的读者也能确认"这确实是他会做的事"。
- 第 3 章：反应改变下一步，某段关系或某场冒险因前两章而实质推进。

读完三章，读者要能回答：这些角色为什么还是他们、原创要素改变了什么、接下来要跨的关系或冒险坎在哪。

## 本章场景写法（按需选 1-2 种，每种给出量化计数）

- 角色互动/羁绊：至少 1 个符合原设的标志性反应（口头禅/习惯动作/固有立场），关系状态较上一场有可追溯变化≥1。失败模式：角色只负责卖梗、关系原地踏步 → 让互动改变两人之间的某个具体认知或距离。
- 战斗或对抗：体现角色固有战法、能力设定与消耗，跨作品对抗按既定兼容规则推进，不报名词。胜负要有依据（准备/情报/规则利用/临场判断）。失败模式：为让某方赢而对手突然变蠢 → 给对手一个合理失误来源。
- 日常反差：把角色放进非日常或错位情境，用符合原设的反应制造反差笑点或温情，至少 1 个标志性反应。失败模式：反差靠 OOC 制造 → 改成"性格不变、情境改变"的错位。
- 剧情推进：本场必须让主线事件、关系或认知中的至少一项向前走，原创要素承担其后果。失败模式：靠原剧情复述占位 → 用角色的新选择推动新进展。

## 成文软区间（是软参考，不是合格线）

句长 20–30 字为主、长短交替；对白约占三成（二次元语感偏轻快多对话）；设定与情怀说明打断剧情，比字数偏离更严重。数字不达标不算错，角色被梗和复述淹没才算错。

## 交付自检（每条勾不上就回到对应写法改）

- [ ] 本章主要角色至少有一次符合原设的标志性反应 → 勾不上回「角色互动/羁绊」。
- [ ] 本章推进了一段关系或一场冒险中的至少一项 → 勾不上回「剧情推进」。
- [ ] 跨作品/对抗场面遵守了开书先定的兼容规则，胜负有依据 → 勾不上回「战斗或对抗」。
- [ ] 章末留了新羁绊/新对手/新谜题/更高目标之一的钩子 → 勾不上补钩子。

## 量化反套路红线（写完核对，超标即改）

- 角色 OOC 写崩人设：0 处（任何偏离核心动机/语言习惯/关系底线的写法必须先有经历支撑）。
- 靠原作情怀堆砌而无新剧情推进的段落：0 段（每段必须带角色新选择或关系变化）。
- 跨作品互动无规则随意乱斗、凭人气定胜负：0 次。
- 用泛化人设代替标志性反应（谁都能说的台词/动作）：0 处。
