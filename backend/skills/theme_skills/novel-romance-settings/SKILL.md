# 情感关系设定设计 Skill

## 定位

关系层能力，搭配都市、历史、幻想等主题材使用，为其提供慢热、双向暗恋、久别重逢、先婚后爱、契约关系、欢喜冤家、破镜重圆等关系模式，不自动把情感副线扩成主线。

一句话检查（写完本章自问）：本章关系是否因一个具体事件推进了一步——信任加深、边界后移、脆弱被暴露或冲突爆发——而不是仅靠一段心动独白撑场？只剩心跳和形容词，就回到「相识—信任—脆弱—冲突—选择」里挑一格重写。

## 设计前必答（缺一项先问，不要用"以后再说"填空）

- 参与者年龄：双方年龄与年龄差，涉及未成年人须保持适龄且非性化。
- 关系起点：初见时的身份、处境与彼此认知。
- 吸引来源：一句话说清对方哪一点触动了角色，不用"命中注定"搪塞。
- 边界：各自不可退让的底线与拒绝权。
- 权力差异：身份、资源、信息、依赖上的不对等及其影响。
- 预期结局：走向复合、成婚、和解还是遗憾收场。

## 落地规则（量化）

- 为关系建立相识、信任、脆弱暴露、冲突、选择五格的可观察变化，每格至少落一次具体事件而非独白。
- 每次相处至少改变认知、边界、信任三者之一，勾不上就补一个让对方"重新认识/退让/托付"的动作。
- 亲密程度按格推进，不允许跨格跳跃：陌生 → 熟识 → 信任 → 依赖 → 承诺，每跳一级须有铺垫事件。
- 契约不替代同意，婚姻不免除尊重；控制、伤害、越界不能被叙事直接当作爱的证明。

## 与主题材协作

- 情感副线服务主线，不喧宾夺主：主题材的目标推进段落 ≥ 情感专属段落，除非用户明确要求以感情为主线。
- 矛盾来自价值观、生活目标、责任或尚未修复的伤害；不靠"一句话就能澄清却被无限拖延"的误会推进。
- 与都市/历史/幻想技能组合时以用户已确认设定为准，发现互斥规则先澄清，不静默覆盖对方的世界规则。

## 交付自检（每条勾不上就回到对应规则改）

- [ ] 本章关系有可观察的变化（信任/边界/脆弱/冲突/选择之一）→ 勾不上回「落地规则」。
- [ ] 情绪落到了具体行动或选择，而非停留在心理独白 → 勾不上：删独白、加动作。
- [ ] 甜或虐都有前置积累与相应代价，不是凭空发糖或强行虐 → 勾不上补铺垫或代价。
- [ ] 配角承担独立功能，未被降级为纯粹的嫉妒/误会制造机 → 勾不上给配角一个自己的诉求。

## 量化反套路红线（写完核对，超标即改）

- 把控制、羞辱、越界包装成浪漫：0 处。
- 旁白直接宣布"很爱/深爱"而无对应行动证据：0 次。
- 亲密度无铺垫的跨格跳跃：0 次。
- 靠反复误会、失忆、车祸/绝症推进关系：全书 ≤1 次。
- 涉及未成年人的关系描写：始终保持适龄、非性化，越界即删。
