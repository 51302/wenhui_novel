# 历史权谋小说 Skill

## 读者承诺

这类读者追的是「在身份秩序和利益格局里，靠谋略与取舍改变处境」。朝代、官职、礼制都是格局的外壳，不是内容本身。真正的爽点是：一步落子，权力或处境跟着变。

一句话检查（写完本章自问）：删掉所有朝代名、官职名、礼制名词之后，这一章是否还剩「某人做了一步博弈 → 权力或处境变了」？如果只剩考据堆砌和场面铺陈，这章还没进入权谋，回到「落子—代价—格局变化」重写。

## 开书先定（缺一项先问，不要用"到时候再编"填空）

- 时代语境与身份秩序：什么朝代/家族/宫闱，谁在上、谁在下，规矩由谁定。
- 主角身份与筹码：他是什么名分，手里有什么别人没有的（信息/血缘/财权/人脉）。
- 核心权力格局与对手：主要博弈在谁与谁之间，主角的对手要什么。
- 可用与禁用的手段：礼法、规矩、身份约束下，哪些手段能用、哪些一用就翻船。
- 前三章权谋承诺：读者前三章能看到的最大一次博弈爽点。
- 中期两道博弈门槛：接下来两个必须靠谋略跨过的关口。

## 前三章承诺链

- 第 1 章：抛出一个可执行的处境压力（不是背景铺陈），主角必须当场落一步子。
- 第 2 章：主角的筹码/手段可验证——换一个在场的人也能描述"他凭什么、做了什么"。
- 第 3 章：一步博弈改变格局，权力关系或主角处境因前两章而变化。

读完三章，读者要能回答：主角要什么、他手里有什么别人没有的、接下来要过哪道博弈门槛。

## 本章场景写法（按需选 1-2 种，每种给出量化计数）

- 谋略博弈—代价：落子≥1（试探/设局/借势/交换），代价或反制≥1（暴露/失信/受制/失一子），格局变化≥1（权力或处境挪动）。失败模式：算无遗策且零损耗 → 每步谋划都收一笔代价。
- 身份/礼法冲突：冲突必须卡在名分、礼制、上下级或公开场合限制上，而非现代逻辑。主角赢要靠对规矩的利用或迂回。失败模式：角色随意越权、无视礼法 → 让规矩成为可用/可困的实体约束。
- 结盟/背叛：盟友有独立诉求，结盟有条件、背叛有铺垫和动机。失败模式：盟友只为衬托主角 → 给他一个与主角冲突的利益点。
- 情报与试探：有限信息下的判断，情报有真假、有来源成本、有被反用的风险。失败模式：主角全知全能 → 明确他不知道什么、误判过什么。

## 成文软区间（是软参考，不是合格线）

句长 20–30 字为主、长短交替；对白约占三成，含蓄但指向清楚，注意称谓与礼节；潜台词密度宜高，话里有话。考据说明打断博弈，比字数偏离更严重。数字不达标不算错，落子被考据淹没才算错。

## 交付自检（每条勾不上就回到对应写法改）

- [ ] 本章有明确的一步博弈落地（设局/试探/结盟/反制/夺权/破局）→ 勾不上回「谋略博弈—代价」。
- [ ] 主角的手段和胜负有可追溯依据（筹码/信息/规矩利用）→ 勾不上回「情报与试探」。
- [ ] 冲突落在身份、礼法或利益上，而非现代逻辑 → 勾不上回「身份/礼法冲突」。
- [ ] 章末留了新对手/新把柄/新交换/更高权位之一的钩子 → 勾不上补钩子。

## 量化反套路红线（写完核对，超标即改）

- 主角计谋、对手全程降智配合：0 次（对手要有合理应对）。
- 违背时代礼法/常识来救场：0 次。
- "权谋"只靠旁白宣布聪明而无具体落子：0 处。
- 一步登天、无代价夺权：≤1 次（再多必须插入代价与反制）。
