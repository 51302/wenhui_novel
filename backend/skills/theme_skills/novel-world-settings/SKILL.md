# 小说世界设定设计 Skill

适用分类：架空历史、异世界、现代超凡、星际文明、末世社会、平行世界与多世界背景。本 skill 是 capability 层，辅助任意主题材创作，不替代题材本身。

## 定位

世界设定是「辅助层」，为题材和人物服务，不能用设定百科取代故事。设定的价值只在被人物用到时才成立。

一句话检查（每写一条设定自问）：本次设定是否直接影响某个人物在具体场景里的选择？如果答不上「谁、在哪个场景、因为它做了什么不同的决定」，这条设定就是无用设定，删掉或改写成能落地的版本。

## 设计前必答（缺一项先问，不要用"到时候再编"填空）

- 核心公设：这个世界最根本的一条规则是什么，一句话说清（如"死亡可逆但代价递增"）。
- 不可违背的限制：哪条边界任何人任何情况都不能突破，它是冲突的天花板。
- 故事尺度：本作聚焦一城/一国/一星系还是多世界？设定精度只需覆盖这个尺度。
- 物理底盘：地理、人口、资源、技术或力量水平各处于什么量级。
- 区域差异成因：不同地区为何既相似又不同，答案必须落到资源/历史/制度，而非"设定如此"。

## 落地规则（量化）

- 顺序固定：先写核心公设与不可违背限制，再铺地理/人口/资源细节，最后才是风俗名词。顺序颠倒即返工。
- 因果链推导：从资源与生产 → 分工 → 贸易 → 权力 → 法律 → 文化，每一环都能回答"为什么是这样"，断链≥1处即补齐。
- 四层信息分离：客观真相 / 社会共识 / 阵营宣传 / 角色认知，四者可以互相矛盾；每处关键设定标清人物"知道的是哪一层"。
- 呈现方式：单章集中解释世界观的段落 ≤1 段，其余规则一律靠人物在场景中触碰规则来显现（借鉴 inkcraft"先给结果再补必要解释"——先让读者看到规则的后果，再补最小必要说明）。

## 与主题材协作

- 优先级：设定服从用户已确认设定与人物设定；三者冲突时以用户确认项 > 人物设定 > 本次新增设定。
- 发现互斥先澄清：本次设定与已有设定或人物动机相斥时，先提出并询问，不静默覆盖既有内容。
- 不临时救场：不为消除某个障碍而临时新增关键设定；障碍应由已存在的规则与人物能力去解。
- 不改历史：既定设定一经确认，后文承担其持续后果，不擅自重写时间线或力量上限。

## 交付自检（每条勾不上就回到对应小节改）

- [ ] 本次设定是否落到具体人物的成本或选择？ → 勾不上回「定位」删无用设定。
- [ ] 是否避免了开篇集中堆世界观百科？ → 勾不上回「落地规则」改成场景呈现。
- [ ] 新增设定是否检查了对经济/历史/剧情的连锁影响？ → 勾不上回「落地规则」补因果链。
- [ ] 未定内容是否都留白、没被当既定事实使用？（必须为 0 处违规） → 勾不上回「四层信息分离」标注认知层级。

## 量化反套路红线（写完核对，超标即改）

- 开篇集中堆世界观百科段：0 段（有则拆进后续场景）。
- 临时新增设定救场：0 次（障碍必须由既有规则与人物解决）。
- 只写宏大设定却无角色具体选择的段落：0 处。
- 未知/未定区域被当作既定事实使用：0 处。
