# 轻小说幻想 Skill

## 读者承诺

轻小说读者追的是「辨识度极高的角色 + 轻快对话 + 日常与冒险交替的反差感」。校园、异世界、游戏、公会都是舞台外壳，真正被记住的是「只属于这个角色」的反应和一次次关系或处境的小推进。

一句话检查（写完本章自问）：删掉所有设定名词（学校名、技能名、世界观名）之后，这一章的角色是否还剩「只属于他」的反应，以及一次关系或处境的小推进？如果只剩气氛和名词堆砌，这章还没进入轻小说，回到「角色记忆点 + 一步推进」重写。

## 开书先定（缺一项先问，不要用"到时候再编"填空）

- 主角强辨识度特征：口癖、反差或执念，一句话说清"他和别人不一样在哪"。
- 核心关系群：3-5 个会反复互动的角色，各自和主角的化学反应功能。
- 日常舞台与冒险线：日常发生在哪、冒险目标是什么，两者如何切换。
- 轻快基调的边界：哪些损失、伤害、严肃时刻不许用玩笑消解掉。
- 前三章角色承诺：读者前三章能记住主角的哪个专属反应。
- 中期两段阶段冒险：接下来两个成段落的冒险高潮各是什么。

## 前三章承诺链

- 第 1 章：主角用一个独特反应（口癖/反差/执念）立住人设，并当场做一次选择，而不是只被介绍。
- 第 2 章：角色关系的化学反应可验证——换一个在场的人也能描述"这俩人凑一起会发生什么"。
- 第 3 章：日常或冒险推进下一步，主角的处境或关系因前两章而变化。

读完三章，读者要能回答：主角是个什么样的人、他身边有谁、接下来要一起去干什么。

## 本章场景写法（按需选 1-2 种，每种给出量化计数）

- 角色互动出笑点/反差：每场至少 1 个可复述的角色记忆点；对白笑点或反差 ≥2 处。失败模式：所有人说话一个声音、吐槽同质化 → 给每人一个只属于他的反应或说话方式。
- 日常—冒险切换：日常桥段必须透露关系、埋线索或制造后续选择，记忆点 ≥1；切换时保留过渡而非硬跳。失败模式：日常空转不推进任何东西 → 让日常埋下冒险的因或角色的果。
- 阶段性冒险推进：目标推进 ≥1，能力展示遵循已建立规则并体现角色个性化用法，代价或波折 ≥1。失败模式：随意加新能力/新等级解决问题 → 在既有规则内用角色特长破局。
- 关系升温：至少 1 次关系状态的可验证变化（更近/更疏/新身份揭露），记忆点 ≥1。失败模式：好感凭空上涨无事件支撑 → 用一次具体互动作为依据。

## 成文软区间（是软参考，不是合格线）

对白占比偏高（约三到四成），句子轻快短促、长短交替；严肃场景减少无效玩笑。数字不达标不算错，角色没有专属反应、对白同质化才算错。

## 交付自检（每条勾不上就回到对应写法改）

- [ ] 本章至少有 1 个可复述、可区分、可传播的角色记忆点 → 勾不上回「角色互动出笑点/反差」。
- [ ] 配角至少有一次独立反应而非纯背景板 → 勾不上：给配角一个和主角不同的诉求或反应。
- [ ] 日常桥段推进了关系、线索或选择之一 → 勾不上回「日常—冒险切换」。
- [ ] 章末推进了主线冒险或角色关系之一 → 勾不上补钩子。

## 量化反套路红线（写完核对，超标即改）

- 全章无一处角色专属记忆点：0（必须 ≥1）。
- 配角只做背景板、无独立反应：0（至少 1 个配角有独立反应）。
- 轻快基调下把严肃损失一笔带过消解掉：0 次。
- 泛化人设词（善良/勇敢/温柔）代替具体行为：0 处（必须落到可复述动作）。
