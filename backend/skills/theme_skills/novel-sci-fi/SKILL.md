# 科幻小说 Skill

## 读者承诺

科幻读者追的是「一个自洽的技术/世界设定 → 被推演出人的处境与选择」。设定名词、术语、公设都是外壳，被推演出的后果与选择才是内容本身。

一句话检查（写完本章自问）：删掉所有术语和设定名词之后，这一章是否还剩「某个规则/技术带来了具体后果 → 有人必须据此做选择」？如果只剩名词堆砌和未来感气氛，这章还没进入科幻，回到「设定推演—后果」重写。

## 开书先定（缺一项先问，不要用"到时候再编"填空）

- 核心科幻设定：一句话说清本书凭什么与众不同（哪条技术/世界公设）。
- 设定的规则、代价与边界：它能做什么、消耗什么、在哪失效、被谁掌握。
- 世界尺度与社会影响：这条设定改变了能源、通信、经济、治理或阶层中的哪些。
- 主角处境与欲望：他被这条设定卡在什么位置，最想要什么。
- 前三章设定承诺：读者前三章能亲眼验证到的最大推演后果。
- 中期两道推演门槛：接下来两个必须靠设定逻辑跨过的障碍。

## 前三章承诺链

- 第 1 章：抛出一个可执行的处境压力（不是设定讲解），主角必须当场据此做选择。
- 第 2 章：核心设定可验证——换一个在场的人也能描述"这技术产生了什么效果"。
- 第 3 章：设定后果改变下一步，主角处境或目标因前两章的推演而变化。

读完三章，读者要能回答：这条设定的规则与代价是什么、主角被它逼到哪、接下来要靠它跨什么门槛。

## 本章场景写法（按需选 1-2 种，每种给出量化计数）

- 设定推演—后果：新推演≥1（从既定公设推出一个新结论），代价或限制≥1（能源/时间/权限/伦理成本），处境变化≥1（推演结果逼出新选择）。失败模式：设定只在旁白解释、不落到具体后果 → 改成让某人被这条推演逼着行动。
- 技术冲突/故障：故障或对抗必须体现设定的规则与边界，不能只报参数与型号。转折要有可追溯的诱因（误操作/资源枯竭/条件超限/对手利用规则）。失败模式：故障凭空发生、无前置铺垫 → 补一个先行埋下的限制或征兆。
- 社会/伦理博弈：各方有独立立场与利益，难题源自既定公设而非临时道德口号。失败模式：配角只为衬托主角正确而存在 → 给他一个基于自身处境的合理诉求。
- 探索发现：新环境/新现象带竞争者与风险成本，发现物附带缺陷或后患。失败模式：发现即解局、无副作用 → 加代价、加未知威胁或加争夺者。

## 成文软区间（是软参考，不是合格线）

句长 20–30 字为主、长短交替；对白约占两成；解释密度以不打断动作为限。解释性设定打断动作，比字数偏离更严重——数字不达标不算错，动作被设定说明淹没才算错。

## 交付自检（每条勾不上就回到对应写法改）

- [ ] 本章有明确的设定后果落地（推演/故障/博弈/发现之一）→ 勾不上回「设定推演—后果」。
- [ ] 关键转折有可追溯的技术或条件依据 → 勾不上回「技术冲突/故障」。
- [ ] 本章至少有一次"设定被验证"的具体动作，而非名词描述 → 勾不上：删名词、加行动、加限制。
- [ ] 章末留了新推演/新限制/新威胁/更高门槛之一的钩子 → 勾不上补钩子。

## 量化反套路红线（写完核对，超标即改）

- 纯设定讲解段（不含动作与选择）：全章 ≤1 段。
- 用"未来科技万能"绕过此前已立的限制：0 次（再用必须先付出对应代价）。
- 技术故障/突破无铺垫凭空发生：0 次。
- 名词堆砌但无具体后果（术语罗列却不影响处境）：0 处。
