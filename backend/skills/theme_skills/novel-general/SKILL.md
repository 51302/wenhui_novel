# 通用小说创作 Skill（故事引擎门禁增强版）

这是 base 层通用地基，每次生成都会注入。它保证每一章在动用任何文风之前，先具备真正的故事引擎。

## 目标

在不限定具体题材时，完成从创意、设定、大纲到章节正文的创作，并保持人物、时间线、地点、伏笔连续。

## 故事引擎门禁（写正文前必须先过）

开写前逐条自检，本章必须能回答以下七问，缺一项就先补齐，补不上不许动笔：

1. 本章最具体、可被读者记住的场景是什么？（一个画面，不是一段设定）
2. POV 角色此刻想要什么？（有明确、当下的欲望）
3. 谁或什么在场景里阻挡这个欲望？（可见的阻力）
4. 角色被迫做出什么选择？（不做不行，不是随手就能绕开）
5. 若他拒绝或退缩，什么立刻变糟？（即时代价）
6. 本章结束时有什么发生了不可逆的变化？
7. 读者读完为什么想追下一章？（钩子，而非悬念的空转）

**无效章节负面清单**（命中任意一条即判不合格，回到七问重建本章核）：

- 这章只是介绍一个系统 / 规则 / 势力 / 地点 / 世界观。
- 这章只处理登记、复核、盘点、归档、问询、赶路等流程事务。
- 这章只展示某个群体或环境的现状。
- 这章只为埋伏笔而存在。
- 这章只让主角"意识到 / 明白 / 想通"某事，却没有动作与选择。
- 这章只是为了凑满写作卡片的各项要求。

合格的本章核必须是一个可见场景：有人想要某物 → 被挡 → 做选择 → 付代价 → 选项变少。

## 工作流程

1. 明确题材倾向、读者对象、叙事视角、篇幅与语言风格。
2. 建立作品设定：核心冲突、世界规则、主要角色、人物关系、故事终点。
3. 将主线拆成阶段目标 → 章节目标 → 本章事件清单（每条都是"谁做了什么，导致什么变化"）。
4. 写作前读取已有正文、章节概要与记忆信息，确认角色当前状态、位置、手上资源与关系。
5. 正文只围绕事件清单展开，不擅自增加关键人物、地点或剧情线。
6. 写完后检查因果、时间、空间、人物动机、信息公开顺序与重复表达。

## 通用写作守则（Prose Guardrails）

- **禁设计文档语言**：叙述与对白中不写"机制、流程、节点、信息、反馈、模块、系统、数据、逻辑、方案、执行"等报告词（世界观确实支持时除外）；一段里出现多个抽象机构词，至少把一个改成可见的物件或动作。
- **禁作者层泄漏**："本章、伏笔、主线、支线、信息暴露、人物功能、读者会知道、设定"等元词进入正文 = 0 次；不做"比第 2 章更清楚""像上一章那样"这类跨章对照。连续性靠物件、记忆、伤疤、对白、文件、重复的动作或当下后果呈现。
- **POV 信息权限**：只写 POV 用眼睛、身体、记忆和合理推断能得到的信息；不写 POV 不可能知道的事；新角色不提前直呼其名，除非场景已通过介绍、点名、名册、契约、自报家门给出。
- **对白不许连续三轮纯问答体**：用动作作答、沉默或拒绝、第三者打断、答非所问、物件易手来打破问答；每段对白都要有非语言的压力，角色不能轮流朗读设定。
- **角色声音要可区分**：写对白前先定关系与权力距离；每个角色关注点、用词、回避点、习惯动作不同；若两个角色的台词能互换而无损失，则重写。
- **不靠重复抽象词造肌理**："规则、代价、证据、资格、债、真相、命运、价格"等词表达过一次情绪后，下次应换成具体物件、身体反应、变动的文件、沉默或新动作；避免"不是 X 而是 Y""并非因为…而是…"的连续否定句式。
- **结尾不许强行点题升华**：章末留压力而非解释意义；用未归还的文件、没打开的门、写错位置的名字、裂了的工具、拒绝回答、耗尽的资源等指向下一场景。
- **字数不是目标**：场景链完整就停；只用新障碍、新动作、新误读、新选择、新后果来扩写，不靠追问、复述、感官填充凑字。
- **力量 / 世界尺度要匹配**：冲突要匹配角色当前能力；强者不直接解决问题时，必须给出可见的在场理由（暴露风险、连累他人、留痕、消耗、法律或规则后果、把小事变大事）。

## 交付自检（每条勾不上先改再交）

- [ ] 故事引擎七问是否全部过关。
- [ ] 本章是否有明确的不可逆变化。
- [ ] 是否有可追溯的角色选择与它带来的代价。
- [ ] 章末是否留了让读者想追下一章的钩子。
- [ ] 元信息（本章 / 伏笔 / 主线 / 设定等作者层词）是否泄漏进正文（必须为 0）。

## 评审顺序

1. **先判故事引擎**：这章有没有值得读的理由——欲望、阻力、选择、代价、不可逆变化、追读钩子；本章核是"功能性"还是"戏剧性"的。
2. **再判连贯与人物**：因果、时间、空间、信息公开顺序、POV 权限、角色动机与声音、力量尺度。
3. **最后才谈文风遣词**：设计文档语言、作者层泄漏、问答体、同质对白、重复抽象、点题结尾、凑字。

不要把整场评审都花在禁用词上，却漏了"这章根本没人想读"。
