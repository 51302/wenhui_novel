# 游戏题材小说 Skill

## 读者承诺

游戏读者追的是「在明确的游戏规则/数值系统里，靠操作与策略获得可验证成长」。等级、技能、装备、排名都是这套系统的外壳，真正让读者上头的是「主角做了一个操作或决策 → 系统按规则给出反馈 → 实力或排名或处境变了」。

一句话检查（写完本章自问）：删掉所有技能名、数值、装备名之后，这一章是否还剩「某个操作/策略 → 实力或排名/处境变了」？如果只剩技能特效描写和数值堆砌，这章还没进入游戏，回到「操作/策略—代价—下一门槛」重写。

## 开书先定（缺一项先问，不要用"到时候再编"填空）

- 游戏世界规则与数值体系：这是真实游戏、全息虚拟世界还是游戏规则化异界；等级、属性、伤害怎么结算，退出与死亡机制是什么。
- 职业/技能机制与代价：主角职业定位、核心技能、冷却与消耗、装备与掉落来源；每个强力手段的上限和失败条件是什么。
- 主角处境与目标：他现在被什么卡住（菜、穷、被针对、掉分），最想要什么（上分、通关、翻身、赚钱）。
- 竞争格局/公会势力：谁在和他抢资源、抢排名、抢副本首杀；主要公会或势力各自要什么。
- 前三章游戏承诺：读者前三章能看到的最大操作爽点或翻盘时刻。
- 中期两道门槛：接下来两个必须打过的副本、赛事或经营危机。

## 前三章承诺链

- 第 1 章：抛出一个可执行的游戏内压力（不是背景与数值介绍），主角必须当场做一个操作或决策。
- 第 2 章：机制可验证——换一个同场的玩家/围观者也能描述"他这波是怎么做到的"，靠的是操作、走位或规则利用，而非旁白说他厉害。
- 第 3 章：反馈改变下一步，主角的等级/排名/处境或目标因前两章的操作而变化。

读完三章，读者要能回答：主角想要什么、他在这套规则里有什么别人没有的操作或认知、接下来要打哪个坎。

## 本章场景写法（按需选 1-2 种，每种给出量化计数）

- 打怪/副本—掉落—代价：进展≥1（升级/首杀/拿到关键掉落），代价≥1（消耗药水/减员/暴露实力/占用冷却），下一门槛≥1（更硬的 BOSS 或新机制）。失败模式：无成本通关、掉落必出神装 → 改成付出减员或资源后才拿到。
- PVP 对战：必须体现技能取舍、数值差、走位与消耗，不能只报技能名。胜负要有依据（预判/打断/装备克制/操作细节/资源换算）。失败模式：对手为让主角赢突然送人头 → 给对手一个合理的失误来源或误判。
- 公会/经营博弈：资源、版本、人心、现金流之间做取舍，配角有独立诉求而非只负责崇拜。失败模式：对手公会全程当背景板 → 给他们一个和主角冲突的目标与行动。
- 机制探索：主角发现规则漏洞或隐藏机制，须付出试错成本，且漏洞被发现后运营/他人会响应。失败模式：漏洞永远独享无人管 → 加入被封堵或被抢跑的压力。

## 成文软区间（是软参考，不是合格线）

句长 20–30 字为主、长短交替；对白约占两成；解释性文字与数值罗列打断动作，比字数偏离更严重。数字不达标不算错，操作被数值和技能名淹没才算错。

## 交付自检（每条勾不上就回到对应写法改）

- [ ] 本章有明确目标达成（升级/首杀/上分/破局/翻盘/揭机制）→ 勾不上回「打怪/副本—掉落—代价」。
- [ ] 主角的成长或胜利有可追溯的操作或策略依据 → 勾不上回「PVP 对战」。
- [ ] 本章至少有一次"操作/机制被看见"的具体动作，而非技能名与数值描述 → 勾不上：删名词数值、加操作、加代价。
- [ ] 章末留了新对手/新版本/新副本/新机制/更高排名之一的钩子 → 勾不上补钩子。

## 量化反套路红线（写完核对，超标即改）

- 无成本刷级/爆神装：≤1 次（再多必须插入代价或竞争者）。
- 对手为让主角赢送人头：0 次。
- 违背已设定游戏规则临时救场（改数值/删冷却/凭空加机制）：0 次。
- 技能名/数值罗列但无实战体现（走位、取舍、克制、消耗）：0 处。
