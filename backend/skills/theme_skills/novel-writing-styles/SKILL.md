# 小说语言与叙事风格控制

## 定位

文风是「表达层」，只管「怎么说」，不替代题材、情节模式或人物关系设定。

核心顺序：先有故事引擎（欲望 / 阻力 / 选择 / 代价 / 变化），再谈文风。文风让一场好戏更好看，不能让流畅的语言掩盖一场死戏。

一句话检查（落地前自问）：删掉所有形容词、比喻和修辞之后，这一段是否还剩「谁想要什么 → 遇到什么阻力 → 做了什么选择 → 付出什么代价」？如果只剩辞藻和气氛，先回故事引擎，别急着调文风。

## 风格维度（先确认再落地）

落地前先锁定七个可量化维度，任一缺失先向用户确认或从样本提取：

- 视角 / 人称：第一或第三、单视角或多视角、视角权限（角色只知道什么）。
- 叙事距离：贴近角色内心，还是拉远做旁观。
- 时态与语体：过去 / 现在时；书面、口语还是混合。
- 句长：主句长区间与长短交替节奏。
- 词汇密度：实词与修辞词比例，避免抽象词堆砌。
- 修辞强度：比喻、通感、象征的使用频率上限。

六种基调各自要点：

- 简洁：强调动作与留白，删可删的解释，让事件自己说话。
- 细腻：关注感受的变化过程，写「怎么变」而非「很难受」这类标签。
- 幽默：靠反差与时机，不靠密集抖包袱，严肃损失处不消解。
- 冷峻：控制评判，用事实与细节代替作者下结论。
- 诗性：意象必须服务场景与情绪，不为美而美。
- 热血：先建立目标与代价，让爽点有铺垫、有付出。

## 落地规则（量化）

- 从用户样本提取高层特征（节奏、密度、意象系统），不复制其独有句段。
- 句长长短交替，避免全篇同长；建议每 5–8 句内出现一次明显的长短对比。
- 比喻密度控制：同一意象全章有节制复现（建议 ≤3 次），不同段落不重复同一喻体。
- 仿写在世作者：改用「高层特征组合」（如冷句 + 短段 + 具体名词），而非照抄其招牌句式或标志性段落。
- 抽象词与情绪标签比例受限：能用动作、画面、对白承载的情绪，不用「悲伤 / 震撼」直接贴标签。

## 与主题材 / 作家风格协作

- 与题材 skill（如 novel-xuanhuan）叠加时：题材决定「写什么」（境界、爽点、冲突结构），文风决定「怎么表达」（句式、密度、修辞）。
- 与 writer- 作家风格 skill 叠加时：作家风格提供高层特征组合，本 skill 负责在当前作品设定内落地。
- 冲突时以「作品设定与人物设定」为准，文风让步。
- 润色时不改变事件顺序、因果链或人物动机；只调表达，不动结构。

## 交付自检

- [ ] 视角 / 人称 / 时态全章稳定，无无依据的漂移。
- [ ] 句长有起伏，未出现整段同长句堆叠。
- [ ] 文风未掩盖空洞剧情（须避免：辞藻华丽但没有欲望 / 阻力 / 选择 / 代价）。
- [ ] 未改动原剧情、因果或人物动机（改动数须为 0）。
- [ ] 情绪由动作与画面承载，而非抽象标签直接告知。

## 量化反套路红线（写完核对，超标即改）

- 全篇句长均匀无起伏：须打散，至少制造明显长短交替。
- 靠堆砌华丽词 / 重复抽象词造「肌理」：0 处，改用具体名词与动作。
- 文风高分掩盖废章（无事件推进的纯气氛章）：0 章。
- 未授权照抄在世作者招牌段落 / 标志性句式：0 处，一律改为高层特征组合。
- 情绪标签直接告知（「他很痛苦」类）替代描写：全章 ≤2 处。
