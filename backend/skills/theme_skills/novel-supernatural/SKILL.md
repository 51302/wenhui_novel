# 灵异小说创作 Skill

## 读者承诺

灵异读者追的是「未知与规则带来的恐惧张力」，环境本身是主角之一——一处光线、一段回声、一条不能踩的门槛，都在参与叙事。鬼怪、禁忌、怪谈都是这份张力的外壳，不是内容本身。恐惧来自「一处不对劲被感知 → 人物的认知或处境被迫改变」。

一句话检查（写完本章自问）：删掉所有「鬼、诡异、恐怖」字眼之后，这一章是否还剩「一处不对劲被感知 → 认知或处境变了」？如果只剩气氛词和惊吓名词堆砌，这章还没进入灵异，回到「不对劲—揭示」重写。

## 开书先定（缺一项先问，不要用"到时候再编"填空）

- 灵异规则体系与代价：异常怎么触发、怎么规避、违反后承担什么，代价必须具体可执行。
- 怪谈/禁忌清单：本篇有哪些"不能做"的条目，每条对应一个后果。
- 可信与不可信的信息边界：哪些是目击、哪些是传闻、哪些是角色的臆测，读者要能分辨。
- 恐怖基调尺度：心理压迫、民俗诡秘还是血腥直给，先定上限，全篇不越界。
- 前三章恐怖承诺：读者前三章能感到的最大一次"寒意"是什么。
- 中期两道规则门槛：接下来两个必须靠理解规则才能跨过的坎。

## 前三章承诺链

- 第 1 章：抛出一个可感知的异常压力（不是背景传说），主角必须当场做反应或选择。
- 第 2 章：不对劲可验证——换一个在场的人也能描述"哪里偏了"，而非只有主角一人的错觉。
- 第 3 章：异常回应主角的行为，处境或认知因前两章而改变，规则露出第一角。

读完三章，读者要能回答：异常的规则是什么、主角想活着做成什么、接下来哪条禁忌绕不开。

## 本章场景写法（按需选 1-2 种，每种给出量化计数）

- 不对劲—揭示：埋不对劲≥1（声音/空间错位/重复细节/正常物的偏差），被感知≥1（人物察觉并反应），揭示≥1（认知或处境改变一格，能不解释就不解释）。借鉴「恐怖先行、战斗在后」：先让读者不安，再谈对抗。失败模式：气氛铺满却什么都没变 → 让不对劲落到一个具体后果上。
- 规则试探/破禁：人物试探禁忌的边界，代价必须当场兑现。失败模式：违反禁忌毫无后果 → 补一个即时或延时的代价。
- 民俗解谜：靠对仪式、传说、地方规矩的理解推进，线索区分目击/传闻/猜测。失败模式：结尾临时掏出一件法器救场 → 解法必须来自前文已给的规则。
- 遭遇：与异常正面相触时，胜负或脱身要有依据（规则利用/牺牲/临场判断），恐怖先行、战斗在后。失败模式：靠 Jump scare 堆砌代替氛围 → 删惊吓、加感知与代价。

## 成文软区间（是软参考，不是合格线）

句长 20–30 字为主、长短交替；对白约占两成；解释性文字打断氛围，比字数偏离更严重。数字不达标不算错，诡异被解释淹没、余味被说干净才算错。

## 交付自检（每条勾不上就回到对应写法改）

- [ ] 本章有一处"不对劲"被明确感知并落到后果（认知/处境改变）→ 勾不上回「不对劲—揭示」。
- [ ] 异常的规则或禁忌在本章有可验证的体现，而非空气般的气氛 → 勾不上回「规则试探/破禁」。
- [ ] 解法来自前文已铺的规则或线索，不是临时出现的法器 → 勾不上回「民俗解谜」。
