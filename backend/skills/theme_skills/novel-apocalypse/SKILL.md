# 末世灾难生存小说 Skill

## 读者承诺

末世读者追的是「在资源与环境压力下，每个选择都有代价的生存推进」。丧尸、灾变、变异体都是压力的外壳，不是内容本身——真正让人往下读的是「他为了活下去做了取舍 → 资源/威胁/关系被改写 → 下一步更难走」。

一句话检查（写完本章自问）：删掉丧尸、灾变、末世这些名词之后，这一章是否还剩「资源、威胁或关系发生了可量化的变化」？如果只剩气氛和灾难名词堆砌，这章还没进入生存，回到「搜刮—代价—新威胁」重写。

## 开书先定（缺一项先问，不要用"到时候再编"填空）

- 灾变类型与规则：灾难是什么、怎么扩散、有哪些不可逆后果，一句话说清。
- 资源经济：水、食物、弹药、燃料、安全屋各有多少，怎么消耗、怎么补——不能凭空来。
- 威胁等级与升级曲线：当前最大威胁是什么，接下来会怎样变强或变多。
- 团队成员及分歧：谁在队里、各有什么技能与伤病、谁和谁在目标上冲突。
- 前三章生存承诺：读者前三章能看到的最硬核的一次生存推进。
- 中期两道生存门槛：接下来两个必须靠取舍才能跨过的障碍。

## 前三章承诺链

- 第 1 章：抛出一个即时生存压力（缺水/被围/断粮，不是背景介绍），主角必须当场做出取舍。
- 第 2 章：威胁与规则可验证——换一个在场的人也能描述"这灾变/这威胁是怎么运作的"。
- 第 3 章：前两章的行动改变处境，主角的资源、威胁或团队关系因之前的取舍而变化。

读完三章，读者要能回答：主角靠什么活着、最大的威胁是什么、接下来要跨哪道生存门槛。

## 本章场景写法（按需选 1-2 种，每种给出量化计数）

- 搜刮—代价—新威胁：获得≥1（补给/情报/工具），代价≥1（消耗/受伤/暴露/暴露行踪），威胁升级≥1（引来更强敌人或触发新规则）。失败模式：进屋随手拿满物资毫发无伤 → 改成付出噪声/时间/伤亡后才拿到。
- 遭遇战：必须体现地形、弹药余量、体力和武器选择，不能只报威胁名。主角脱险要有依据（预判/陷阱/牺牲诱饵/规则利用）。失败模式：敌人为让主角赢突然降智 → 给威胁一个合理的失误来源。
- 团队分歧/抉择：成员有独立诉求（保谁、走哪条路、分多少水），冲突来自目标与资源而非单纯吵架。失败模式：队友只为衬托主角正确而存在 → 给他一个和主角对立且成立的方案。
- 环境求生：温度、能见度、污染、噪声、体力必须真实影响行动与判断。失败模式：环境只是背景板 → 让环境直接改写这次行动的成败或代价。

## 成文软区间（是软参考，不是合格线）

句长 20–30 字为主、长短交替；对白约占两成；解释性文字打断行动，比字数偏离更严重。数字不达标不算错，生存动作被解释和设定淹没才算错。

## 量化反套路红线（写完核对，超标即改）

- 无代价获取补给（进场即拿满、毫发无伤）：≤1 次（再多必须插入代价）。
- 主角光环导致队友降智送死：0 次。
- 灾变规则临时改写救场（规则突然为主角开绿灯）：0 次。
- "全员平安脱险、无任何损失"式过关：0 次。
