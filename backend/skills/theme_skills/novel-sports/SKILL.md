# 体育竞技小说 Skill

## 读者承诺

体育读者追的是「靠训练积累与临场判断赢得可验证的竞技推进」。项目、赛制、战术都是这条推进的外壳，不是内容本身；实力和名次的变化，才是读者要看的东西。

一句话检查（写完本章自问）：删掉所有项目术语、招式名、战术黑话之后，这一章是否还剩「某次训练/比赛决策 → 实力或名次变了」？如果只剩热血气氛和术语堆砌，这章还没进入竞技，回到「训练—代价—提升」重写。

## 开书先定（缺一项先问，不要用"到时候再编"填空）

- 项目规则与胜负判据：什么项目、哪个赛制版本、怎么算赢，一句话说清。
- 主角当前水平与短板：他现在处在什么段位，最要命的弱项是什么。
- 对手/队伍格局：主要竞争者是谁，各自强在哪、动机是什么。
- 训练资源与代价：他能用的教练、场地、时间、身体本钱，以及练下去要付出什么。
- 前三章竞技承诺：读者前三章能看到的最大竞技看点。
- 中期两场关键赛：接下来两场必须打的硬仗，各自要跨什么坎。

## 前三章承诺链

- 第 1 章：抛出一个可执行的竞技压力（不是履历介绍），主角必须当场做出训练或比赛决策。
- 第 2 章：实力可验证——换一个在场的人（对手/教练/队友）也能描述"他这一手强在哪"。
- 第 3 章：结果改变下一步，主角的名次、位置或目标因前两章的投入而变化。

读完三章，读者要能回答：主角想赢什么、他靠什么在追赶、接下来要打的硬仗是什么。

## 本章场景写法（按需选 1-2 种，每种给出量化计数）

- 训练—代价—提升：投入≥1（针对短板的具体训练/复盘），代价≥1（体能透支/伤病风险/牺牲的时间或关系），提升≥1（可量化的进步或新解法）。失败模式：一夜苦练直接脱胎换骨、提升无任何代价 → 改成付出后才拿到的进步。
- 比赛/对抗：必须体现战术、临场调整、体能消耗，不能只报比分。主角获胜要有依据（战术针对/情报/规则利用/体能分配/临场读牌）。失败模式：对手为让主角赢突然失误 → 给对手一个合理的失误来源。
- 战术博弈：赛前部署与赛中变招要能被拆解，对手也在调整。失败模式：一个战术从头用到尾无人破解 → 让对手打出针对，逼主角二次调整。
- 队内磨合：教练、替补、主力各有独立诉求，不只负责喊加油。失败模式：队友只为衬托主角而存在 → 给他一个和主角冲突的位置或打法之争。

## 成文软区间（是软参考，不是合格线）

句长 20–30 字为主、长短交替；对白约占两成；解释规则的文字打断比赛节奏，比字数偏离更严重。数字不达标不算错，动作被规则讲解淹没才算错。

## 交付自检（每条勾不上就回到对应写法改）

- [ ] 本章有明确竞技结果（晋级/夺冠/翻盘/失利/破纪录/入选）→ 勾不上回「训练—代价—提升」。
- [ ] 主角的成长或胜利有可追溯依据 → 勾不上回「比赛/对抗」或「战术博弈」。
- [ ] 本章至少有一次"实力被看见"的具体动作，而非履历或术语描述 → 勾不上：删术语、加动作、加代价。
- [ ] 章末留了新对手/新赛事/新短板/更高目标之一的钩子 → 勾不上补钩子。

## 量化反套路红线（写完核对，超标即改）

- 无训练铺垫突然爆种逆转：0 次（逆转必须有此前的投入或调整作依据）。
- 对手为让主角赢而失误：0 次（失误必须有合理来源）。
- 靠"热血喊口号"而非战术/实力赢下比赛：0 次。
- 比分/名次罗列但无比赛过程与决策：0 处。
