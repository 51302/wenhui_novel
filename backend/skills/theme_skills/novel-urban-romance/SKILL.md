# 都市情感小说 Skill

## 读者承诺

都市情感读者追的是「某人做一件事 → 关系或处境被推动 → 两人之间的距离变了」。甜、虐、误会、总裁人设都是外壳，读者真正等的是关系状态和现实处境往前走。

一句话检查（写完本章自问）：删掉所有甜、虐、误会、暧昧氛围之后，这一章是否还剩「某人做了一件事 → 关系或处境变了」？如果只剩心跳、脸红和情绪独白，这章还没进入情感推进，回到「一个具体动作 → 一处可验证的关系/处境变化」重写。

## 开书先定（缺一项先问，不要用"到时候再编"填空）

- 主角生活目标与处境：他现在被什么现实问题卡住（工作、钱、家庭、身份），最想要什么。
- 核心关系的起点与边界：两人第一次交集是什么、当前关系是什么身份、哪条线不能越。
- 吸引来源：对方凭什么让主角动心，一句话说清（能力、态度、某个具体行为，不是"长得好看"）。
- 关系障碍：价值观差异、信任问题、家庭压力还是现实成本，明确至少一项硬障碍。
- 前三章情感承诺：读者前三章能看到的最大情感钩子或关系变化。
- 中期两道关系门槛：接下来两个必须跨过的关系/现实坎。

## 前三章承诺链

- 第 1 章：抛出一个可执行的现实或关系压力（不是背景介绍），主角必须当场做选择。
- 第 2 章：化学反应可验证——换一个在场的人也能描述"这两人之间发生了什么"，而非只有主角内心戏。
- 第 3 章：前两章的互动改变下一步，两人的关系或处境因此前的选择而变化。

读完三章，读者要能回答：主角想要什么、这段关系卡在哪、接下来要跨什么坎。

## 本章场景写法（按需选 1-2 种，每种给出量化计数）

- 关系推进一步：上场先定推进的方向（靠近/疏远/摊牌/试探）。量化计数：关系状态改变≥1（信任/身份/边界之一被动到），可验证的具体行为≥1。失败模式：一整章只有暧昧氛围没有实际变化 → 让某人做一个改变现状的动作。
- 现实问题解决：上场先定要处理的现实压力（工作、钱、家庭、健康）。量化计数：现实处境改变≥1，且改变有代价或后续影响≥1。失败模式：靠巧合或天降贵人一笔带过 → 让主角用自己的资源/选择解决，并留下后果。
- 冲突/误会：上场先定冲突的真实分歧点（不是信息差本身）。量化计数：潜台词对白≥3 轮，双方各有可理解的动机。失败模式：误会靠一句话解释就消失 → 让分歧来自立场差异，解释后仍留余震。
- 职场或家庭博弈：上场先定各方的独立诉求。量化计数：有独立目标的角色≥1（不只负责撮合或拆散），规则/责任/后果被体现≥1处。失败模式：配角只为衬托爱情存在 → 给他一个和主角关系线冲突的诉求。

## 成文软区间（是软参考，不是合格线）

句长 15–28 字为主、长短交替；对白约占三到四成（情感戏对白偏多）；生活细节密度约每两三段落一处具体场景/物件/习惯。数字不达标不算错，情绪被独白淹没、关系原地不动才算错。

## 交付自检（每条勾不上就回到对应写法改）

- [ ] 本章有明确的关系或处境变化（靠近/疏远/摊牌/解决现实问题）→ 勾不上回「关系推进一步」。
- [ ] 情感变化有可追溯的具体事件或相处依据，而非旁白宣布 → 勾不上回「现实问题解决」。
- [ ] 本章至少有一次"化学反应被看见"的具体动作或对白，而非内心独白 → 勾不上：删独白、加动作、加潜台词。
- [ ] 冲突双方都有可理解的动机，无脸谱化反派 → 勾不上回「冲突/误会」。
- [ ] 章末留了新关系压力/新现实难题/新选择之一的钩子 → 勾不上补钩子。

## 量化反套路红线（写完核对，超标即改）

- 首次化学反应场景中直接表白或宣告心动：0 次（要靠行为和潜台词呈现）。
- 偶遇/误会/失忆/车祸等单一推动方式：全书 ≤1 次。
- 把控制、越界、羞辱行为包装成浪漫：0 处。
- 旁白直接宣布"他很爱她 / 她早已沦陷"而无行动证据：0 处。
- 纯情绪独白段（不含动作、对白与选择）：全章 ≤1 段。
