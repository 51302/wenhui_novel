# 玄幻小说子分类创作

## 定位

- 本 skill 是 `novel-xuanhuan` 的细化层（capability 层），不独立成书，须与主玄幻 skill 叠加使用。
- 先按主 skill 确定主成长路径（境界体系、核心爽点循环），再用本 skill 挂载辅修子分类。
- 只补「子分类差异化机制」，不重复主 skill 的通用规则（爽点循环、前三章承诺链、成文软区间等）。
- 覆盖范围：东方玄幻、仙侠修真、宗门/家族、御兽、炼丹炼器、体修、玄幻经营；分类是能力清单，不强迫用户全用。

## 子分类差异化要点

每条子分类必须落到「具体成本 / 门槛」，不同路径各有优势与短板，一人不能无成本精通全部。

- 宗门 / 家族：明确资源分配规则（贡献点、功法权限、丹药配给）与对应义务（任务、护山、传承责任）；获得资源必有对等付出。
- 御兽：明确契约方式、灵兽自主性（有独立意愿，可违抗、可背叛）与培养成本（灵材、时间、契约反噬风险）。
- 炼丹炼器：明确材料稀缺度、工序门槛（火候/阵纹/心神）、成功条件与失败损耗（材料炸炉、经脉受损、声誉受损）。
- 体修：明确身体负担（淬体极限、旧伤累积）与恢复周期（闭关时长、灵药依赖），力量以肉身透支换取。
- 经营：建立生产链、交易网络、防御体系与人口/人才需求；扩张受资源、地盘、敌对势力三重约束。

## 落地规则（量化）

- 冲突必须围绕稀缺资源 / 传承权限 / 组织责任 / 个人道途之一展开，不做无根由的斗气。
- 比赛、秘境、交易各承担不同冲突功能：比赛争排名与权限，秘境争机缘与生死，交易争资源与信息——不只换地点重复夺宝。
- 辅修不能突然跨越已设定门槛：跨阶炼丹、越级御高阶兽、体修硬扛境界差，都须先补足前置条件或付出可见代价。
- 关键转折由可追溯的行为、线索或条件促成；偶然只能引出问题，不能反复代替人物解决问题。

## 与主玄幻 skill 协作

- 主 skill 管通用爽点循环（获得—代价—下一阈值、战斗依据、章末钩子）；本 skill 只管子分类专属机制（契约反噬、炸炉、贡献点、经营链）。
- 两者叠加时，主 skill 的循环是骨架，本 skill 的机制是这一章的具体成本与门槛来源。
- 规则冲突时以作品已确认设定为准；发现互斥先向用户澄清，不静默覆盖任何一方。

## 交付自检

- [ ] 本章子分类机制是否落到具体成本 / 门槛（而非只提名词）→ 勾不上回「子分类差异化要点」补成本。
- [ ] 是否出现一人无短板精通全部路径（须避免）→ 出现即给该路径加代价或短板。
- [ ] 辅修是否越过已设定门槛（须 0）→ 有则补前置条件或代价，或降回合规范围。
- [ ] 是否只换地点重复同类夺宝（须避免）→ 让比赛 / 秘境 / 交易各承担不同冲突功能。

## 量化反套路红线（写完核对，超标即改）

- 辅修无代价跨越已设定门槛：0 次（有则补前置或代价）。
- 一人无短板精通全部子分类路径：0 处（每条路径至少保留一项短板）。
- 子分类机制沦为背景板、对本章事件无实际作用：0 处（每次出现须影响选择或结果）。
