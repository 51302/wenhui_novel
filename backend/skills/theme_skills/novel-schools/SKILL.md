# 小说流派结构设计

## 定位

流派 = 叙事推进模式，属于「结构层」，回答"故事靠什么向前走"，与题材（写什么）、文风（怎么说）正交。玄幻可以是凡人流也可以是无敌流，都市可以是种田流也可以是幕后流——流派不是门派，也不是语言风格。

一句话检查（写完本章自问）：本章是否体现了主流派的核心推进逻辑（凡人流的一步步积累、苟道流的风险评估、无敌流的责任转移、种田流的投入产出、幕后流的信息控制、群像流的视角接力），而不是只在简介里挂了个流派标签？如果抽掉标签本章推进逻辑不变，说明流派没落地，回到对应流派要点重写。

## 各流派差异化要点

- 凡人流：核心是「积累」。每一步战力、资源、人脉都来之不易，读者要能看见成本与来路；杜绝天降机缘让积累瞬间失效。
- 苟道流：核心是「风险评估与机会成本」。苟是主动选择而非被动躲，每次不出手都要算清代价；但不能长期不行动，否则变成停滞流水账，须有被逼出手或主动收网的节点。
- 无敌流：核心是「把压力从『打不过』转向别处」。矛盾不再是战力差，而是责任（该救谁）、信息（不知道真相）、以及无法用武力解决的问题（人心、规则、两难抉择）。
- 种田经营流：核心是「投入产出闭环」。资源→建设→收益→再投入要形成可追踪循环；不能只有数据报表和收益播报，须落到具体人、事、冲突上。
- 幕后流：核心是「限定信息渠道与控制范围」。主角掌控力来自布局而非全知，明确他能看到什么、伸手到哪、盲区在哪；不许临时开天眼补全信息。
- 群像流：核心是「视角任务分配」。每个视角承担独立的推进任务，视角切换须延续或抬升悬念，而非机械轮流报流水账。
- 反派视角：核心是「区分自我辩护与行为后果」。可以让反派有逻辑自洽的动机，但叙事须让读者看清其行为的真实代价，不美化、不让辩护替代后果。

## 落地规则（量化）

- 确认主流派与读者期待，一部作品只设一个主流派；最多引入 1-2 个必要辅助模式支撑主线，不机械叠加所有套路。
- 按流派建立一条持续压力线（贯穿全书的核心张力）：凡人流=安全与机遇，苟道流=保命与错失时机，无敌流=能力与责任/信息，种田流=扩张与维护，幕后流=掌控与失控，群像流/反派视角=个人利益与他人代价。
- 主角优势（战力、谨慎、布局、资源）可以解决某类矛盾，但不能消灭所有矛盾；每章至少保留一个主角优势无法直接抹平的问题。
- 关键转折由可追溯的行为、线索或条件促成；偶然可以引出问题，不能反复代替人物解决问题。

## 与主题材 / 通用 skill 协作

- 分工：流派决定「怎么推进」，主题材 skill（玄幻/都市/悬疑等）决定「写什么」，通用 skill 兜底人物与场景规则。三者叠加时以用户明确要求与已确认设定为准。
- 转换主流派须有明确事件驱动（重大失败、身份剧变、目标达成后进入新阶段），不能中途无理由突然更换，也不能背弃作品开篇给读者的核心承诺。
- 与主题材冲突时以作品设定为准：主题材规定世界规则与卖点，流派服从这些设定来组织推进方式，发现互斥先澄清，不静默覆盖。

- [ ] 流派标签没有代替人格：谨慎者仍有欲望、强者仍有盲区、幕后者仍有盲区、群像各自有诉求 → 勾不上补人物内在。
