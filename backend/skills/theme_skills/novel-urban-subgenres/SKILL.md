# 都市小说子分类创作 Skill

## 定位

都市题材的细化能力层，覆盖职场、商战、创业、行业文、娱乐圈、都市生活、都市异能与神豪叙事。爱情主线交给 novel-romance-settings，本 skill 只管职业/行业/财富的机制与后果。行业事实不得被爽点替代：现实里行不通的操作，不能因为"主角光环"就成立。

一句话检查（写完本章自问）：本章的职业/行业机制，是否真实影响了人物的选择与结果？如果职业只是背景板、换个行业情节照样成立，说明机制没落地，回到「子分类差异化要点」重写。

## 子分类差异化要点

- 职场：写职责与绩效——KPI、汇报线、权限边界、考核结果，晋升靠可核对的业绩而非嘴炮。
- 商战/创业：盯现金流、股权与客户——每一次扩张都要说清钱从哪来、股权怎么稀释、客户为何买单。
- 娱乐圈：写作品生产与声誉——一部作品的立项、拍摄、发行、口碑发酵，红或糊都要有作品与舆论依据。
- 行业文：守流程与专业限制——真实的操作规程、准入门槛、行业周期，专业细节经得起同行看。
- 都市异能：先限定能力对现实秩序的影响——能做什么、代价是什么、会不会被现实规则（法律/监管/他人）反制。
- 神豪：追踪财富来源、支出与社会反馈——钱从哪来、花在何处、社会与他人如何回应，绝不让金钱万能。

## 落地规则（量化）

- 开写先选 1 个主子类 + 必要辅线（辅线 ≤2），并确认时代、城市层级、职业门槛、现实或超现实基调，缺项先问不硬编。
- 商业成功必须有交易逻辑与风险：一笔成功交易至少写清「买方动机 + 我方筹码 + 潜在风险」三项，缺一项即为凭空成功。
- 用项目/交易/作品/生活事件构建阶段闭环：每个阶段有目标、阻力、人物选择、结果，成绩兑现后须呈现成本与新责任（≥1 项）。
- 每个场景至少推进事件、关系、认知中的 1 项；章末承接实际结果，不强行制造同类悬念。

## 与主题材协作

- 与 novel-romance-settings 分工：情感线的推拉、告白、关系定位交给情感 skill，本 skill 只提供职业/行业/财富语境。
- 都市异能不能随时绕过此前已确立的重要现实约束（法律、监管、资金、他人意志）；要绕过须先付出对应代价并留下后果。
- 与其他主题材 skill 组合时，规则冲突以用户明确要求及已确认的作品设定为准；发现互斥先澄清，不静默覆盖。

## 交付自检（每条勾不上就回到对应小节改）

- [ ] 本章行业/职业机制真实可信，删掉它情节就不成立 → 勾不上回「子分类差异化要点」。
- [ ] 本章的商业/职业成功有交易逻辑与风险，不是凭空达成 → 勾不上回「落地规则」补三要素。
- [ ] 本章没有靠羞辱配角来制造爽点 → 勾不上删掉羞辱段，换成可追溯的实力/信息博弈。
- [ ] 本章异能未绕过此前重要现实约束（须为 0 次）→ 勾不上加代价或改设定。

## 量化反套路红线（写完核对，超标即改）

- 用羞辱配角反复造爽点：0 次。
- 商业成功无交易逻辑、凭空达成：0 处。
- 行业事实被爽点替代（现实行不通却硬成立）：0 处。
- 神豪金钱万能、支出无社会反馈：0 处。
- 异能随意绕过此前重要现实约束：0 次。
