# 奇幻小说创作 Skill

## 读者承诺

奇幻读者追的是「在自洽的魔法/异界规则里，靠冒险与抉择推进」。主角在既定规则下做一件事 → 规则给出可验证反馈 → 处境改变。魔法名、种族名、势力名都是这条循环的外壳，不是内容本身。

一句话检查（写完本章自问）：删掉所有魔法名词、种族名、势力名之后，这一章是否还剩「某人用规则做了一件事 → 处境变了」？如果只剩宏大氛围和名词堆砌，这章还没进入奇幻，回到「施法—代价—后果」重写。

## 开书先定（缺一项先问，不要用"到时候再编"填空）

- 魔法体系规则：能力如何发动、上限在哪、代价与边界与禁忌是什么，一句话说清可验证规则。
- 世界/种族/势力格局：地理资源如何推导出族群、信仰、贸易与敌友关系，不只罗列地图。
- 主角处境与欲望：他现在被什么卡住，最想要什么，为此愿付什么。
- 冒险线目标：这趟旅程要抵达/夺取/阻止的具体目标，可衡量是否达成。
- 前三章奇幻承诺：读者前三章能看到的最大奇观与最硬的抉择。
- 中期两道冒险门槛：接下来两个必须跨过的障碍或抉择点。

## 前三章承诺链

- 第 1 章：抛出一个可执行的压力（不是世界观导览），主角必须当场在规则内做选择。
- 第 2 章：魔法可验证——换一个在场的人也能描述"施了什么法、付了什么代价、发生了什么"。
- 第 3 章：反馈改变下一步，主角处境或冒险目标因前两章的抉择而变化。

读完三章，读者要能回答：主角想要什么、他能用什么规则做别人做不到的事、接下来要跨什么坎。

## 本章场景写法（按需选 1-2 种，每种给出量化计数）

- 施法—代价—后果：施法须体现规则、消耗、限制，不能只报咒语名。施法≥1（在规则内发动），代价≥1（法力/身体/时间/关系/道德的消耗或反噬），后果≥1（处境改变或新限制）。失败模式：魔法无代价万能解决一切 → 改成付出后才生效、超限即反噬。
- 战斗：必须体现魔法规则、环境影响、招式取舍与消耗，不能只报法术名。主角获胜要有依据（准备/情报/规则利用/牺牲/临场判断）。失败模式：敌人为让主角赢突然变蠢 → 给敌人一个合理的失误来源。
- 探索发现：秘境/遗迹/异界机会须有竞争者与风险成本，收获带缺陷或后患。失败模式：捡到神器就无限变强无副作用 → 加代价、觊觎者或权限限制。
- 势力博弈：不同族群内部保留立场差异，配角有独立利益与去留理由，不只负责衬托或送经验。失败模式：种族标签取代人格 → 给他一个和主角冲突的具体诉求。

## 成文软区间（是软参考，不是合格线）

句长 20–30 字为主、长短交替；对白约占两成；解释性文字打断动作或冒险节奏，比字数偏离更严重。数字不达标不算错，动作被世界观解说淹没才算错。

## 交付自检（每条勾不上就回到对应写法改）

- [ ] 本章有明确目标推进（施法达成/战斗胜负/探索发现/结盟破局/揭示规则）→ 勾不上回「施法—代价—后果」。
- [ ] 主角的成长或胜利有可追溯依据 → 勾不上回「战斗」。
- [ ] 本章至少有一次"魔法在规则内被看见"的具体动作，而非名词描述 → 勾不上：删名词、加施法过程、加代价与限制。
- [ ] 章末留了新敌人/新限制/新线索/更高目标之一的钩子 → 勾不上补钩子。

## 量化反套路红线（写完核对，超标即改）

- 魔法无代价万能（施法不付消耗、不受限制即解决问题）：0 处。
- 临时新增设定救场（凭空冒出未铺垫的规则/神器/血脉解围）：0 处。
- 只写宏大世界观无角色具体选择（纯设定介绍段，不含动作与抉择）：全章 ≤1 段。
- 种族/魔法名罗列但能力无差异体现：0 处。
