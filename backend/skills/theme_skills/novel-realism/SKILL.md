# 现实题材小说 Skill

## 读者承诺

现实题材读者追的是「在真实生活的成本与关系里，普通人做出有代价的选择而成长」。家庭、乡土、职场、制度都是这条承诺的现场，不是背景板本身。

一句话检查（写完本章自问）：删掉所有煽情词、感慨句、金句之后，这一章是否还剩「某人面对现实压力做了选择 → 关系或处境变了」？如果只剩情绪渲染和道理输出，这章还没进入现实题材，回到「生活成本 → 选择 → 代价与变化」重写。

## 开书先定（缺一项先问，不要用"到时候再编"填空）

- 主角的现实处境与生计：靠什么活着，一个月钱怎么进怎么出，一句话说清。
- 核心关系与矛盾：谁和他绑在一起，为什么放不下也躲不开。
- 社会/家庭约束：户口、彩礼、赡养、编制、房贷、行业规矩，哪几条卡着他。
- 可信的生活细节来源：年代、地域、职业流程从哪来，哪些是已知事实、哪些待核实。
- 前三章现实承诺：读者前三章能看到的最具体的生活压力与选择。
- 中期两道生活门槛：接下来两个必须扛过去的现实关口（如失业、重病、离乡、分家）。

## 前三章承诺链

- 第 1 章：抛出一个具体的生活压力（不是身世感慨），主角必须当场为钱、为人或为一件事做选择。
- 第 2 章：这份压力可被旁观者核实——换一个在场的人也能说出"他家出了什么事、他在为什么发愁"。
- 第 3 章：选择带来后果，主角的关系或处境因前两章而变化，不是原地循环诉苦。

读完三章，读者要能回答：主角靠什么过日子、他被什么绑住、接下来要扛哪道坎。

## 本章场景写法（按需选 1-2 种，每种给出量化计数）

- 生活事件—代价：具体事件≥1（一笔账/一次求人/一趟办事），付出的代价≥1（钱/时间/面子/关系/机会），处境变化≥1。用具体生活细节承载情感，不写"他很难过"，写他数了几次钱、把烟掐了、回信息删了又改。
- 关系冲突/和解：至少两方各有自己的道理与难处，冲突落到具体事（分钱、看病、结婚、赡养）。失败模式：一方全程无理取闹只为衬托 → 给对方一个站得住的理由。
- 社会/制度碰撞：主角撞上流程、规则或身份门槛（窗口、合同、政策、行规），要写清办事的具体步骤与卡点。失败模式：一句话跳过流程直接得到结果 → 补上被卡的环节和成本。
- 日常切片积累：用劳动细节、居住条件、物件和作息堆出压力，平缓段也要改变理解或关系。失败模式：流水账无任何认知或关系变化 → 让这一天里有人明白了一件事。

## 成文软区间（是软参考，不是合格线）

生活细节密度：每场景落到可触摸的物件、动作或数字≥2 处；克制的情绪表达，情绪靠动作和细节外化，直接抒情句全章尽量少。句长 20–30 字为主、长短交替；对白约占两成。细节不达标不算错，用感慨替代场景才算错。

## 交付自检（每条勾不上就回到对应写法改）

- [ ] 本章主角面对现实压力做出了具体选择（花钱/求人/办事/取舍/离开/留下）→ 勾不上回「生活事件—代价」。
- [ ] 选择带来了可追溯的代价或后果，不是零成本解决 → 勾不上回「关系冲突/和解」或「社会/制度碰撞」。
- [ ] 本章至少有一次情感靠具体细节外化，而非直接说"他很难过/很感动" → 勾不上：删感慨、加动作、加物件。
- [ ] 章末承接实际结果，留了新的生活压力/待办/关系变化之一的钩子 → 勾不上补钩子。

## 量化反套路红线（写完核对，超标即改）

- 用旁白直接宣布情感而无行动支撑：0 处（必须改成可看见的动作或细节）。
- 靠巧合/贵人一次性解决现实困境：0 次（结构性困境不能被偶然抹平）。
- 煽情点全部说满、不留白：0 处（留一处让读者自己接情绪）。
- 脸谱化好人坏人（善恶写在脸上、无各自处境）：0 处（每方给一条站得住的动机）。
