# 武侠小说 Skill

## 读者承诺

武侠读者追的是「在江湖规矩与恩怨中，人物凭武功和抉择完成侠义成长」。招式、门派、内功都是这条成长线的外壳，不是内容本身。

一句话检查（写完本章自问）：删掉所有招式名和门派名之后，这一章是否还剩「某人做出江湖抉择 → 恩怨或立场变了」？如果只剩打斗气氛和名词堆砌，这章还没进入武侠，回到「抉择—代价—立场变动」重写。

## 开书先定（缺一项先问，不要用"到时候再编"填空）

- 主角的武学根基与短板：他会什么、强在哪、致命弱点是什么，一句话说清。
- 江湖格局：门派、势力、恩怨网如何分布，谁与谁有旧账。
- 核心恩怨/夙愿：主角被什么恩仇或心愿驱动，最想了结什么。
- 侠义立场与底线：他为什么出手、什么事绝不做。
- 前三章江湖承诺：读者前三章能看到的最大江湖冲突或恩怨爆点。
- 中期两道江湖门槛：接下来两个必须跨过的对手、规矩或抉择。

## 前三章承诺链

- 第 1 章：抛出一个可执行的江湖冲突（不是背景介绍），主角必须当场做出抉择。
- 第 2 章：武功或身份可验证——换一个在场的人也能描述"他到底有几分本事"。
- 第 3 章：恩怨或立场因前两章的抉择而改变，江湖关系随之移动。

读完三章，读者要能回答：主角想了结什么恩怨、他的武功成色如何、接下来要过哪道江湖门槛。

## 本章场景写法（按需选 1-2 种，每种给出量化计数）

- 比武/生死斗：上场先定胜负赌注与双方成色。战斗须体现武功高下、招式取舍、环境与内力消耗，不能只报招式名；胜负计数：招式互换≥3 回合、体现高下的细节≥2 处。失败模式：反派为让主角赢突然失手 → 给对手一个合理的破绽来源（旧伤/轻敌/被牵制）。
- 恩怨博弈/结义反目：上场先定各方旧账与筹码。诉求计数：在场者独立诉求≥2、立场因本场移动≥1。失败模式：配角只为衬托主角 → 给他一个与主角冲突的江湖诉求。
- 门派/江湖规矩冲突：上场先定规矩条文与违规代价。冲突计数：规矩与人情的两难≥1、抉择带来的后果≥1。失败模式：规矩沦为背景板 → 让规矩实际卡住主角某个选择。
- 机缘—代价：机缘必须有竞争者和风险成本，秘籍或宝物带缺陷、后患或门派觊觎。代价计数：付出≥1（受伤/结仇/失去/暴露）。失败模式：捡到就练成绝世武功无副作用 → 加代价或追债者。

## 成文软区间（是软参考，不是合格线）

句长 20–30 字为主、长短交替；对白约占两成；动作密度在交锋段落偏高。解释性文字打断打斗，比字数偏离更严重。数字不达标不算错，动作被解释淹没才算错。

## 交付自检（每条勾不上就回到对应写法改）

- [ ] 本章有明确的江湖抉择或恩怨了结（比武/复仇/结义/破局/守规/揭恩怨）→ 勾不上回「恩怨博弈」或「比武/生死斗」。
- [ ] 主角的胜负或成长有可追溯依据（准备/情报/旧伤/规则利用/牺牲）→ 勾不上回「比武/生死斗」。
- [ ] 本章至少有一次"武功高下被看见"的具体交锋，而非招式名罗列 → 勾不上：删名词、加交锋、加消耗。
- [ ] 章末留了新恩怨/新对手/新规矩/新夙愿之一的钩子 → 勾不上补钩子。

## 量化反套路红线（写完核对，超标即改）

- 无代价习得绝世武功：≤1 次（再多必须插入代价或后患）。
- 反派为让主角赢突然失手：0 次（须给出合理破绽来源）。
- "侠义"沦为口号而无具体取舍：0 次（须落到一次实际抉择上）。
- 招式名罗列但无高下体现：0 处。
