# 悬疑推理小说 Skill

## 读者承诺

悬疑读者追的是「与主角共享可验证线索 → 在信息博弈中逼近真相」的推理循环。气氛、悬念、诡计都是这条循环的外壳，不是内容本身。读者要能拿着和主角一样的线索，自己下场推。

一句话检查（写完本章自问）：删掉所有气氛渲染词和惊悚词之后，这一章是否推进了「线索→推理→嫌疑范围变化」？如果只剩阴森氛围和吓人场面，这章还没进入推理，回到「投放线索—据线索推理—嫌疑范围收缩或转移」重写。

## 开书先定（缺一项先问，不要用"到时候再编"填空）

- 核心谜题：读者从头追到尾的那个问题，一句话说清（谁干的/怎么干的/为什么）。
- 真相全貌：作者必须先知道事件真实经过、时间线、作案手法和决定性证据，不许边写边编。
- 可用线索池与投放顺序：列出真线索、旁证、伏笔，各自在哪章投放、哪章回收。
- 嫌疑人及动机/不在场：每名嫌疑人的欲望、秘密、作案机会、不在场证明与其漏洞。
- 前三章悬念承诺：读者前三章能看到的最强钩子与第一批可验证线索。
- 中期两次信息反转：接下来两个必须发生的判断颠覆点，各由哪条线索引爆。

## 前三章承诺链

- 第 1 章：抛出可执行的谜题钩子（不是背景铺陈），主角必须当场介入、开始行动。
- 第 2 章：给出可验证线索——换个在场的人也能记下"看到/查到了什么"，读者能自己抄进笔记。
- 第 3 章：线索改变嫌疑范围，某人被排除或某人浮出，主角的追查方向因前两章而转向。

读完三章，读者要能回答：核心谜题是什么、手里握着哪几条线索、当前谁最可疑。

## 本章场景写法（按需选 1-2 种，每种给出量化计数）

- 公平线索投放：上场先定这条线索指向谁。真线索≥1（读者可自行记录），且揭示时才追加的决定性事实为 0（不许把关键事实藏到最后硬凑）。失败模式：线索只在结局由侦探口述 → 提前落地为读者可见的物证/证词。
- 误导/红鲱鱼：上场先定它误导的方向和最终澄清方式。红鲱鱼≥1，但不得违背已给事实。失败模式：靠隐瞒真事实制造误导 → 改成"事实全给、只错在解读"。
- 审讯/取证：上场先定这场问话要撬动哪个矛盾点。要体现提问目的、心理博弈、证据压力，产出≥1条新信息或1处证词矛盾。失败模式：审讯只报结论 → 写出攻防回合与松口瞬间。
- 推理复盘：上场先定这次复盘收缩到哪个嫌疑范围。所用证据须全部前文出现过，嫌疑人排除/锁定≥1。失败模式：复盘引入新证据 → 只许重组已知线索。

## 成文软区间（是软参考，不是合格线）

句长 18–30 字为主、长短交替；对白约占两到三成（审讯章可更高）；信息密度以"每千字至少落地一条可验证线索或一次判断变化"为粗准。数字不达标不算错，线索被气氛淹没、读者无法跟推才算错。

## 交付自检（每条勾不上就回到对应写法改）

- [ ] 本章推进了线索→推理→嫌疑范围变化 → 勾不上回「公平线索投放」。
- [ ] 至少有一条读者能自己记下的可验证线索 → 勾不上回「公平线索投放」。
- [ ] 误导公平：没有靠隐瞒已知事实制造误解 → 勾不上回「误导/红鲱鱼」。
- [ ] 反转/推理只用前文出现过的证据 → 勾不上回「推理复盘」。
- [ ] 章末留了新问题/新矛盾/新嫌疑之一的钩子 → 勾不上补钩子。

## 量化反套路红线（写完核对，超标即改）

- 瞒匿关键事实搞机械降神（藏事实到最后硬翻盘）：0 次。
- "做梦/巧合/凑巧撞见"敷衍破案：0 次。
- 揭示时才第一次出现的决定性证据：0 处。
- 主角靠灵光一现/直觉而非线索破案：0 次。
