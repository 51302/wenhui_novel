# 无限流小说 Skill

## 读者承诺

无限流读者追的是「在规则明确的副本/任务里，靠信息解读与取舍在高压下求生并成长」。主神、副本、积分、轮回都是这条循环的外壳，不是内容本身——真正让人追的是主角读懂规则、做出取舍、活下来并变强的过程。

一句话检查（写完本章自问）：删掉主神、副本、任务这些名词之后，这一章是否还剩「某个规则解读 / 决策 → 存活率或处境变了」？如果只剩恐怖气氛和名词堆砌，这章还没进入无限流，回到「规则—取舍—代价」重写。

## 开书先定（缺一项先问，不要用"到时候再编"填空）

- 主神/系统规则与代价：进入机制、任务判定、失败惩罚、积分与兑换规则一句话说清，代价必须真实可执行。
- 副本机制与通关判据：本副本的核心规则、隐藏陷阱、明确的通关条件与判定标准是什么。
- 主角能力与队伍：主角凭什么与众不同（信息 / 观察 / 兑换的能力），队伍里各人的定位与私心。
- 轮回/穿梭的长线目标：主空间的终极矛盾、主角穿梭诸天真正想解决的问题。
- 前三章副本承诺：读者前三章能看到的第一个完整副本或最大生存爽点。
- 中期两个高难副本门槛：接下来两个必须靠信息与取舍才能跨过的死局。

## 前三章承诺链

- 第 1 章：抛出一个当场生效的生存压力（不是背景介绍），主角必须在规则下立刻做选择。
- 第 2 章：副本规则可验证——换一个在场队友也能描述"这条规则触发了什么后果"。
- 第 3 章：一次解读或取舍改变下一步，主角的存活处境或队伍格局因前两章而变化。

读完三章，读者要能回答：主角想活着解决什么、他比别人强在哪种能力、接下来要闯什么死局。

## 本章场景写法（按需选 1-2 种，每种给出量化计数）

- 副本规则试探—代价：试探规则≥1（触碰边界 / 验证禁忌），得到反馈≥1（存活 / 受伤 / 触发惩罚），代价≥1（减员 / 掉积分 / 暴露）。失败模式：主角一进副本就全知全能 → 改成用代价换来的规则认知。
- 生死抉择/队伍博弈：把任务目标、队伍利益和道德处境摆到同一张桌上，逼主角在有限信息下取舍。失败模式：队友只负责送死或降智衬托 → 给每个队友独立诉求与合理判断。
- 解谜/信息战：线索有可发现依据，隐藏任务不能结算时凭空追加；主角靠观察、记忆、逻辑破局，不靠系统提示。失败模式：谜底靠作者旁白直接揭晓 → 改成主角逐条推出。
- 通关—结算—新威胁：通关有明确判据，结算积分/道具有取舍，收尾抛出下一个更高威胁。失败模式：无代价通关全员庆祝 → 付出减员或后患才拿到奖励。

借鉴智斗求生：以巧破力，每一步破局都要有可追溯的依据（规则漏洞 / 情报 / 队友配合 / 牺牲 / 临场判断），不能靠主角开挂。

## 成文软区间（是软参考，不是合格线）

句长 20–30 字为主、长短交替；对白约占两成；解释性文字打断生存节奏，比字数偏离更严重。数字不达标不算错，规则推演被大段旁白淹没才算错。

## 交付自检（每条勾不上就回到对应写法改）

- [ ] 本章有明确的规则解读或生存取舍推动剧情 → 勾不上回「副本规则试探—代价」。
- [ ] 主角的存活或胜利有可追溯依据（规则 / 情报 / 配合 / 牺牲）→ 勾不上回「解谜/信息战」。
- [ ] 本章至少有一次"规则被验证"的具体动作，而非气氛描写 → 勾不上：删名词、加试探、加代价。
- [ ] 章末留了新威胁/新规则/新线索/更高目标之一的钩子 → 勾不上补钩子。

## 量化反套路红线（写完核对，超标即改）

- 违反已公布副本规则来救场：0 次。
- 主角靠作者开挂而非信息取胜：0 次。
- 队友降智送死只为推主角上位：0 次。
- 无代价通关：≤1 次（再多必须插入减员 / 掉分 / 后患）。
