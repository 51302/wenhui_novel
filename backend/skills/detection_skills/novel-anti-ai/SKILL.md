# 中文网文反AI检测与去味

本项目已有三道反 AI 防线，本 skill 是第四道「结构/语义」防线，不重复前三道：

- 提示词铁律：`prompts.yaml` 的 `HARD_RED_LINES`（开写前）、`UNIVERSAL_ANTI_AI_GUIDE`、`HUMAN_VOICE_MANDATE`（写作时常驻）、`SELF_CHECK_LIST`（停笔自查）。
- 特征规则库：`conf/ai_feature_rules.json`（66 条 detect/clean，热加载，是阈值的唯一真相源）。
- 程序化清洗：`service/text_cleaner.py`（生成后按密度阈值机械改写）。

目标不是骗过检测器，而是让文字像「老枪」那种赶稿老作者写的：句子长短悬殊、有毛边、不总结、动作直接接动作。冲突时以作品设定和人物设定为最高优先级。

## 分工：本 skill 只管代码补不了的

text_cleaner 已能程序化压掉的统计特征，本 skill 不再花力气讲，只在评分时计入：破折号「——」、冒号超频、省略号、感叹号、「不是X，是Y」句式、三连顿号排比、明喻词换形与「像」字密度、句首连接词（于是/因此/然后/接着）、「那种…像/仿佛」引导句、冗余主语。

本 skill 专治程序改不动的结构与语义问题：

1. 故事引擎空转：整章只在介绍设定/盘点/赶路/让主角"意识到"某事，没有欲望→阻力→选择→代价→不可逆变化。
2. 说明书式设定注入：「简介/修炼条件/功法属性/书名+冒号+规格」标签罗列，或「远程脆近战肉」式教科书利弊对仗。
3. 五感堆砌：一个场景里超过 2 种感官排队写（视觉+听觉+嗅觉+触觉+味觉全覆盖）。
4. 微动作流水线：「眼皮抬→目光停→眉头松→喉结滚」表情进度条；「顿了一下/一瞬/滞/抿了抿/攥了攥」节拍词泛滥。
5. 目光跟随扫描：「目光从X滑到Y又落回Z」名词式目光句反复出现。
6. 剧本式对话：连续「问？答。问？」零动作间隔，或连续 3 句纯对话、连续 3 段「人物+动作」同句式铺排。
7. 工整收尾/点题升华：末句用意象收束（"脚步声被松涛吞没"）或「这X让他Y」把感受拔高成感悟。
8. 缺人味毛边：全章没有真瑕疵（失误/犹豫/被打断），没有无效沟通对话，句长匀速无极短句。

## 0-100 AI 味评分（detect 用，阈值对齐项目）

分数越低越像人写。按项目已量化的密度红线计分，可作为生成后质检参考，不是硬判决。

命中即高危（每项 +12）：
- 「——」破折号出现 ≥1 次（项目要求全章 = 0）。
- 「不是X，是Y」解释句 ≥2 次（全章上限 1）。
- 否定三连排比 / ≥16 字相邻或跨段雷同（换词重写也算）。
- 说明书式标签罗列 或 教科书对仗成句。

超限扣分（每项 +6）：
- 明喻 >3 处（或每 1000 字 >1、单段 >2）。
- 微动作节拍词 >2 处；五官微动作 >2 处。
- 五感命中 >2 种。
- 目光名词式句 >1 处；同「修饰+物件名」短语 >2 次。
- 句首连接词 >1；冒号 >3；四字格某段 >1。

节奏项（每项 +6）：
- 短句独立段（≤12 字）占比不在 15%–35% 区间。
- 段落长度均匀（无长短交替）。
- 缺人味：真瑕疵 <1 处 / 无效沟通对话 <5 处 / 2-7 字极短句 <4 处。

```
score = min(100, 命中高危×12 + 超限项×6 + 节奏项×6)
```

| 区间 | 判定 | 处理 |
|---|---|---|
| 0-20 | 干净 | 直接通过。 |
| 21-40 | 大体像人 | 轻改命中项即可。 |
| 41-60 | 混合 | 定向去味，优先清高危项。 |
| 61-100 | 偏 AI/纯 AI 腔 | 结构性重写，先补故事引擎再清密度。 |

短样本（不足 ~200 字）信号不足，只提示命中项不打分。

## 去味改写顺序（rewrite 用，先结构后密度）

1. 先补故事引擎：若整章空转，回到「谁想要什么→被谁挡→做什么选择→付什么代价→什么不可逆地变了」重建本章核，其余去味都在这之后。
2. 拆说明书：把标签罗列/利弊对仗的设定，改成角色视角或动作带出（"灵力压在指尖，点中就炸"）。
3. 砍五感到 2 种：先定本章两种主感官，其余感官句删掉。
4. 拆微动作流水线：表情进度条只留 1 组，节拍词压到 ≤2，其余用一个具体身体状态或直接不写反应代替。
5. 去目光名词句：「目光落在」改成只写动作（"他偏头看他"），全章 ≤1，且替换写法不重复同一结构。
6. 打散节奏：长句后紧跟 2-7 字极短句（"操。""他没动。"），全章塞 ≥4 处；短句独立段占比拉进 15%–35%。
7. 补人味毛边：加 ≥1 处真瑕疵、≥5 处无效沟通对话。
8. 改工整收尾：末句改成对话戛然而止 / 动作踩空 / 最素事实句，删掉意象收束和「这X让他Y」升华。
9. 最后清密度项：明喻、冒号、连接词、同物件点名按上表压到红线内（多数已由 text_cleaner 兜底，这里只补程序漏掉的）。

去味以减法为主：保留具体事实、动作、数字、专有名词和已经像人写的句子。不新增剧情、人物、设定、台词。已经干净的句子不要动，过度润色本身就是 AI 味。

## 与现有机制的协作

- 阈值以 `conf/ai_feature_rules.json` 为准；本 skill 里的数字是对齐它的引用，若配置调整以配置为准。
- 写作时的常驻铁律交给 `HARD_RED_LINES / UNIVERSAL_ANTI_AI_GUIDE / HUMAN_VOICE_MANDATE`；机械清洗交给 `text_cleaner.py`；本 skill 补「故事引擎 + 结构/语义 + 统一评分」。
- 与题材/作家风格 skill 叠加时：题材决定写什么、作家风格决定怎么表达、本 skill 保证不写成 AI 腔；三者冲突时以作品设定和人物设定为最高优先级。

## 输出要求

- 作为章节生成注入时：只作为写作约束，不在正文里输出检测报告、评分或元信息。
- 作为独立质检时：可输出命中项清单、0-100 评分与按「先结构后密度」排序的去味建议；不编造改写示例之外的事实。
